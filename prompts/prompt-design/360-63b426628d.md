# キャラクターシート生成プロンプト（360度ターンアラウンド）

## 目的

- 選んだキャラクターを、正面・斜め・横・斜め後ろ・背面の全身5面とクローズアップ3面を1枚に収めたキャラクターシートにする画像生成プロンプト。以後の動画差し替えで顔・服の一貫性を保つ参照画像を作るのが目的。

## 前提

- 画像入力に対応したモデル（記事は ChatGPT）。レイアウトのテンプレート画像を添付する前提の書き方で、「the attached image」が指す先がないと構図が安定しない。

## プロンプト本文

```
Use the attached image as a layout template only. 

Create a photorealistic character sheet of my character. 

Top row: five full-body views, front, three-quarter, side, three-quarter back, back. 

Bottom row: three close-ups, front, three-quarter and their signature gesture. 

Plain grey studio background, same face and outfit everywhere, no text.
```

## 使い方

- テンプレート画像と一緒に添付して生成する。
- 得られた1枚を、以降のすべてのモーション生成で参照画像として固定する（言葉で顔を説明すると回ごとに drift するため）。

## 注意点

- プロンプト単体では完結しない（レイアウト用の参照画像が別途必要）。記事中のテンプレート画像は pbs.twimg.com のURLで示されているが、本項目は記事本文のテキストを転記したもので、画像からの起こしではない。
