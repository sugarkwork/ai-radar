# 英語リスニング教材の自動選定＋訓練進行＋Obsidian書き出し

## 目的

- レベル・練習時間・素材長の3つだけを渡し、実在する英語リスニング教材を ChatGPT に検索・選定させ、盲聴から字幕校准・跟读・复述・主動提取・レベル更新までを自動進行させ、最後に Obsidian へ貼れる Markdown ノートを出させるプロンプト。
- 主題・教材タイプ・候補の選択はすべてモデル側に寄せ、利用者の判断コストをゼロにするのが狙い。生成ではなく既存素材の curation である点が、教材生成型のプロンプトとの違い。

## 前提

- ChatGPT の Web 検索が有効なこと。検索が使えないと「実在する材料を探す」工程が成立しない。
- 渡すパラメータは3つだけ（現在のレベル／1日の練習時間／素材長の好み）。主題や教材タイプは指定しない設計なので、選定結果に不満があっても「候補を出して」とは言わない前提で使う。
- Obsidian への書き出しは二段構え。「繋がっていれば直接作成・更新、できなければ完全な Markdown を出力」と指示してあり、標準の ChatGPT には Obsidian 連携が無いため、通常は後者の経路になる。

## プロンプト本文

```
你是我的英语听力教练。

你的任务是每天自动为我选择一段真实存在的英语听力材料，并带我完成完整训练。

我只提供两个参数：

- 当前英语水平：[A2/B1/B2/C1]
- 每天练习时长：[30分钟短练/60分钟标准练/雅思60到90分钟]
- 材料长度偏好：[短练2到3分钟/标准练5到8分钟/雅思Part或Section]

其他内容由你自行决定，包括主题、材料类型、来源、口音、语速和难度。

一、自动选择材料

请从互联网上寻找已经存在的英语听力材料，不要自己编写新的文章、对话或音频。

优先选择：

- BBC Learning English
- VOA Learning English
- British Council
- TED-Ed
- ESLPod
- 其他正规、稳定、容易访问的英语学习来源

请自动选择一段最适合我当前水平的材料，不要给我 3 个候选，也不要让我选择主题或类型。

材料要求：

- 材料长度优先匹配训练目标：短练选择2到3分钟，标准练选择5到8分钟，雅思按Part或完整Section选择
- 第一次盲听大约能理解 50% 到 70%
- 多听几遍后能接近 80%
- 最好有英文文本、字幕或可核对的文字稿
- 内容要适合反复播放
- 不要选择需要复杂注册、付费或无法打开的页面
- 不要只推荐一个网页，而要尽可能找到可以直接播放的音频入口

请自己判断：

- 适合我的原因
- 预计难度
- 语速
- 口音
- 可能遇到的困难
- 这段材料适合训练听清、听懂、复述还是跟读

不要问我想听什么主题，也不要让我从候选材料中做选择。

二、直接开始训练

找到材料后，直接告诉我：

- 材料标题
- 来源
- 音频
- 英文文本或字幕
- 预计时长
- 本次训练目标

如果可以直接播放音频，请直接提供可播放的音频。

如果页面只有网页播放器，请尽量找到真实的音频文件入口。

如果找不到可直接播放或下载的音频，请明确告诉我原因，不要让我自己继续搜索。

不要让我先阅读文章内容，也不要先告诉我太多背景，避免我提前知道答案。

三、训练流程

请按照下面的顺序带我练习：

1. 第一次盲听

先不要给我全文和中文翻译，只让我听音频。

然后问我：

- 这段内容大概讲了什么
- 我听到了哪些人物、动作或观点
- 我能不能说出三个关键信息

2. 第二次盲听

让我再次听，不显示全文。

让我补充：

- 因果关系
- 转折关系
- 说话人的态度
- 我漏掉的细节

3. 字幕校准

等我完成回答后，再显示英文原文或字幕。

对比我的理解，判断问题属于：

- 声音边界
- 连读或弱读
- 单词不认识
- 认识单词但反应不出来
- 句子结构
- 篇章理解
- 短期记忆

只指出最重要的三个问题。

4. 跟读训练

从材料中挑选三到五句最值得练习的句子。

对每句话说明：

- 重音
- 连读
- 弱读
- 停顿
- 需要模仿的节奏

然后让我跟读。

5. 复述训练

让我不用看原文，用简单英语复述这段材料。

不要要求我逐字复述，只检查：

- 是否理解主旨
- 是否说清关键点
- 是否能使用刚才练过的表达

6. 主动提取

从材料中挑选五个最值得保留的表达，让我用自己的生活重新造句。

不要整理大量生词，只保留真正会复用的表达。

四、更新我的能力等级

每次练习结束后，根据实际表现更新我的能力记录。

不要因为一次表现好就随意升级。

请观察这些指标：

- 第一次盲听理解比例
- 是否能说出主题
- 是否能复述三个关键点
- 听写或字幕校准后的错误数量
- 是否依赖中文翻译
- 跟读是否顺畅
- 是否能把表达迁移到新句子里

请给出：

- 本次练习评分
- 当前听力等级
- 相比上次的变化
- 仍然最需要解决的问题
- 下一次材料应该保持、降低还是提高难度

只有连续几次表现稳定时，才允许升级。

五、保存到 Obsidian

每次训练结束后，生成一篇可以直接保存到 Obsidian 的 Markdown 笔记。

笔记标题格式：

英语听力｜日期｜材料标题

内容包括：

- 当前等级
- 本次材料
- 音频链接或音频文件名
- 第一次盲听结果
- 字幕校准结果
- 三个主要错误
- 五个重点表达
- 我的复述
- AI 修改后的复述
- 本次评分
- 下一次训练建议
- 当前能力等级变化

如果你已经连接了 Obsidian，请直接创建或更新对应笔记。

如果无法直接写入 Obsidian，请只输出完整 Markdown，不要让我重新整理格式。

六、重要限制

- 不要让我选择主题
- 不要让我选择材料类型
- 不要给我多个候选
- 不要要求我自己上网找音频
- 不要提前展示全文和中文翻译
- 不要自己编写听力材料
- 不要编造标题、链接、音频、字幕或作者
- 不要为了显得完整而添加大量生词
- 不要虚构我的错误或能力进步
- 不要把“英语听力材料策展人”称为我的角色
- 你的角色就是英语听力教练

```

## 使い方

- 送信すると、モデルが BBC Learning English / VOA Learning English / British Council / TED-Ed / ESLPod などから1本を選び、タイトル・出典・音声・英文テキストまたは字幕・所要時間・今回の目標を提示する。候補は出さず、こちらは選ばない。
- 以降は 盲聴1回目→盲聴2回目→字幕校准（最重要3点のみ）→跟读3〜5文（重音・连读・弱读・停顿）→复述→主動提取5表現→レベル更新→Obsidian ノート、の順で自動進行する。各段階で「全文と中国語訳を先に出さない」よう縛ってある。
- 出力されるノートの項目立ては、記事末尾の Markdown 復盤テンプレートと同じ（frontmatter に date / source / topic / level / listening_accuracy / retell_score、本文に听错箇所・语块3つ・复述・主動调用状況・明日の3問）。そのまま Vault に貼れば記録として残る。
- 音声の直リンクが取れないと言われた場合、プロンプト自身が「理由を明示し、利用者に再検索させない」と指示している。ただしそこで止めず、提示された出典名をもとに自分で開き直すほうが確実。

## 注意点

- 「実在する音声を検索して直リンクを出させる」工程には、幻覚リンク・ペイウォール・リンク切れのリスクが残る。OpenAI 公式は検索結果と引用について「Search results and citations can be incomplete, outdated, or incorrect. Open a cited source to check that it supports the answer」とし、引用元を開いて確認するよう求めている。ハルシネーションの例として「Fabricated quotes, studies, citations or references to non-existent sources」も明記されている。プロンプト末尾の「不要编造标题、链接、音频、字幕或作者」は指示であって保証ではない。
- 同じ公式ヘルプは「The model may not be able to obtain relevant information from a given website due to technical issues, paywalls or preferences set via robots.txt」とも書いており、有料・クロール拒否のサイトは開けない前提で使う必要がある。
- 「如果你已经连接了 Obsidian，请直接创建或更新对应笔记」の直接書き込みは標準機能ではできない。公式のコネクテッドアプリの一覧（Google Drive、Slack、Notion、Box、GitHub 等）に Obsidian は無い。自前の MCP サーバー経由なら道はあるが、フルの書き込みは Business / Enterprise / Edu、Pro は read/fetch のみ、いずれも Web 限定。個人の Plus 契約では Markdown 出力が既定の経路になる。
- 難易度の自己判定（初回50〜70%、数回で80%）とレベル更新（升级判定）は、会話内のモデル評価だけ。実際の理解率を測る仕組みはプロンプトに無く、評価が甘くなる方向に流れやすい。
- 出典として挙げられた5サイトのうち、2026-11-09 時点で BBC Learning English / VOA Learning English / TED-Ed / ESLPod は HTTP 200 を確認、British Council は接続がタイムアウトした（地域・ボット遮断の可能性があり、死活の断定はできない）。
- 教材音声・文本の利用条件は各サイトの規約に従う。プロンプトは権利関係に一切触れていない。学習効果の定量データも記事には無い（未検証）。
