# ADHD実行機能モード化プロンプト7本（日本語版）

## 目的

「やる気が出ない」「タスクが大きすぎて手が動かない」「切り替えができない」といった実行機能の詰まりを、対話の型で強制解除するための7本。投稿者は海外で話題になった手法を日本語の仕事現場向けに再設計したと述べている。各プロンプトは独立して使う。

1. **着手の分解** — 1分以内の極小ステップに割り、最初の物理動作だけ指示させる
2. **集中の再起動** — 前菜3分／メイン15〜20分／サイド5分の行動メニュー
3. **作業監視パートナー** — タイマー付きで伴走させ、報告のたびに1行アクション
4. **タスク切り替え** — 前のタスクの残像を消す3分ルーティン
5. **退屈な作業のゲーム化** — 趣味の世界観でクエスト化（クリア条件・敵・報酬）
6. **見積もりの補正** — 見えない潜伏タスクを3つ炙り出して再計算
7. **脳内の棚卸し** — モヤモヤを「今日中／後まわし／捨てる」に仕分け、今日中だけ1文アクション化

## 前提

- 日本語で使う前提。`【 】` のプレースホルダは自分のタスク名・時間に置き換える。
- 投稿本文には「7つのプロンプト👇」とだけあり、**本文はすべて作者のリプライ**に分割して置かれている。ここでは7本をそのままの順・原文で収録した。
- 特定モデル専用の書式ではない（Claude / ChatGPT / Gemini いずれでも可）。

## プロンプト本文

### 1. 着手の分解

```text
現在【タスク名：例（企画書の骨子作成 / 溜まったメール返信）】を前にして、どうしても手が動きません。

このタスクを「1分以内で終わる極小ステップ」に分解してください。
思考停止でも動き出せるよう、まずは第1ステップとして「今すぐ物理的に手や体をどう動かせばいいか（例：ブラウザのタブを1つ開く、ペンを握る等）」だけを1つ具体的に指示してください。
```

### 2. 集中の再起動

```text
今、脳の刺激が足りずダラけてしまっています。再び集中モードに入るための「行動メニュー」を以下の3段階で提案してください。

1. 前菜（3分）：席を立ってできる軽い身体運動やリフレッシュ
2. メイン（15〜20分）：勢いで一気に終わらせる高密度の単一タスク
3. サイド（5分）：脳を飽きさせないちょっとした創造的・楽しい寄り道
```

### 3. 作業監視パートナー

```text
今から【作業時間：例（25分間）】、【作業内容：例（資料作成）】に集中します。
私の「作業監視パートナー」として伴走してください。

【進め方】
・タイマーをセットして作業に入ります。
・作業終了時、または途中で脱線・挫折しそうになったらここにメッセージを送ります。
・私が報告したら、進捗を褒めつつ次のアクションを1行で指示してください。

まずは「集中開始の合図」と「気合が入る短い一言」を返してください。
```

### 4. タスク切り替え

```text
たった今【前のタスク：例（長時間の会議 / クレーム対応）】を終え、これから【次のタスク：例（新規施策のアイデア出し）】に入りたいのですが、頭が切り替わりません。

前のタスクの疲れや思考の残像をリセットし、次のタスクに必要なエネルギーに切り替えるための「3分間でできる脳内お口直しルーティン（軽いストレッチ、呼吸法、思考の切り離しなど）」を1つ提案してください。
```

### 5. 退屈な作業のゲーム化

```text
今から【退屈な作業：例（溜まったレシートの入力 / スプレッドシート整理）】をやらないといけませんが、億劫でやる気が出ません。

この作業を、私の好きな【趣味・関心：例（RPGゲーム / 推し活 / タイムアタック）】の世界観に置き換えて「クエスト形式」にゲーム化してください。
クリア条件、敵（サボり欲）、クリア時にもらえる自分への小さな報酬を設定してください。
```

### 6. 見積もりの補正

```text
【タスク名】に取り掛かります。
自分では「【想定時間：例（30分）】で終わる」と見込んでいますが、いつも想定の2〜3倍の時間がかかってしまいます。

私が無意識に見落としがちな「見えない潜伏タスク（ファイルの確認待ち、やり直し、細部の体裁調整など）」を3つ炙り出してください。
その上で、現実的な所要時間と無理のない締め切り時刻を再計算してください。
```

### 7. 脳内の棚卸し

```text
頭の中に未完了タスクや不安が溜まりすぎてパンクしています。
下に思いつく限りのモヤモヤを箇条書きで吐き出すので、以下の3つに仕分けて整理してください。

1.「今日中（今すぐ）」：今日やらないと困ること
2.「後まわし（保留）」：今日やらなくても破綻しないこと
3.「捨てる（やらない）」：悩んでも仕方がない、または他人に任せること

※「今日中」に分類したものだけ、迷わず動ける「1文のアクション（具体的な動詞で終わる形）」をつけて返してください。

---
【脳内吐き出しメモ】
・
・
・
```

## 使い方

- 詰まっている種類に合わせて1本だけ貼る。1と7は「動けない」、2と3は「集中が続かない」、4は「切り替え」、5は「退屈」、6は「見積もりが狂う」。
- 6は事前に、7は1日の終わりか朝に使うと効果が測りやすい（見積り誤差と、翌日に残った件数を記録する）。
- 2の「サイド」は休憩ではなく寄り道として設計されている。集中を切らさないための刺激。

## 注意点

- 医療的な主張（ADHD、ドーパミン）は**比喩としての説明**で、臨床的根拠は示されていない。診断・治療の代替にはならない。
- 「1週間分のタスクを4時間で終わらせる」は投稿者の主張で、計測条件の提示はない。
- プロンプトは行動を促すだけで、実際の作業は本人が行う。3の「監視パートナー」はモデル側にタイマー機能はなく、時間管理は自分で行う前提。
- 原文はリプライに分割されている。まとめて1つのプロンプトとして貼ると、意図（1本ずつ使う）から外れる。
