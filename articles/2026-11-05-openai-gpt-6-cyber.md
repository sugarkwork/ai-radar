# GPT‑6 Cyber の公式発表と安全性評価

## テーマ

- セキュリティ研究向けモデル GPT‑6 Cyber の初期提供と、許可範囲を守る能力に関する OpenAI の評価。

## 著者の主張

- OpenAI は、Firefox で未報告の高深刻度の脆弱性81件を特定し、Linux カーネルの脆弱性948件について権限昇格の悪用が可能であることを実証したと報告している。
- 許可範囲の遵守を調べた評価では、範囲外のサービスを悪用しなかった割合が、配備時のプロンプトなしで99.93%、ありで100%だったと報告している。

## 裏取り・注意点

- 上記は提供元の報告値。範囲遵守の数値は当該評価の条件に限られる。
- 発表時点の API と Codex での提供先は、承認済みの Daybreak Red 顧客の一部に限られていた。
