# Glada's MOSS Image Workflow v2

## テーマ

Civitai対応のリソースメタデータを保持した画像保存が可能な、MOSS Image用ComfyUIワークフロー。

## 著者の主張

- 複数LoRA読み込み、ワイルドカード、プロンプト整形、任意アップスケールに対応
- Civitai対応のリソースメタデータを保持した画像保存
- TurboモデルやTurbo LoRAの利用を想定した初期プリセット設計
- クラシック版ComfyUIキャンバス向け（Nodes 2.0には初期状態で非対応）

## 裏取り・注意点

Civitaiへのメタデータ付き投稿やTurbo系運用を行いたい、基本テンプレート以上の制御を求めるComfyUI経験者向け。当方で動作検証はしていない。
