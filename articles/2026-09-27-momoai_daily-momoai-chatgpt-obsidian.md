# 听力练了很久，为什么还是听不懂？ ChatGPT + Obsidian 搭一套可回收的英语听力训练系统

## テーマ

- 中国語圏の英語学習者向けに、リスニングが伸びない原因を「量不足」ではなく「難易度の不一致による噪音级输入」に置き、ChatGPT をコーチ、Obsidian を記録庫にして毎日回せる訓練ループを組む長文記事（2026-09-27、@momoai_daily）。
- 9章構成: 听清/听懂の二層分解 → 音標・弱読・連読・抑揚 → 教材選定（三遍测试法）→ 反復と転移 → ChatGPT の4役割とプロンプト2本 → Obsidian の復盤テンプレート → 30/60分の時間割 → よくある誤り → 総括。
- 使う道具は ChatGPT（材料生成・読み上げ・誤り分類・復盤生成）と Obsidian（Markdown の Vault に記録を蓄積）の2つだけ。特定のプラグイン名や外部 SRS は登場しない。

## 著者の主張

- 失敗の主因は「聞く量」ではない。20%しか分からない素材を流し続けるのは、分からない音を無視する条件反射の訓練であり、数年聞いても変化しない。
- 聞き取りを「听清（音が取れる）」と「听懂（意味が立つ）」に分け、卡点を 声音 / 词义 / 语块 / 篇章理解 / 注意力 の5つに分類してから処方箋を変える。練習順は听清 → 听懂。
- 教材選定は「三遍测试法」。1回目は盲听で主題と3点、2回目も文本なしで因果・転換・態度を補い、3回目で字幕照合して「落としたのは少量の要点だけ」なら本命材料。初回60%・数回で80%が著者の目安。
- 素材は短く、EnglishPod 程度の長さの10本を1単位にして、連読・弱読・抑揚まで再現できるまで周回。次に同一主題で別素材を足す「二層反復」で語汇と语块を定着させる。毎日20〜30分なら素材を頻繁に替えない。
- ChatGPT の役割は4つ: ①レベル・語彙・関心に合わせた材料生成、②盲听→大意1問→回答後に文本開示という校正、③半句预测（文の途中で止めて続きを当てさせる）、④誤りを「音が取れない/単語を知らない/聞いても反応しない/段落関係が掴めない/注意が切れる」に分類。
- 入力→出力の流れは、レベル（A2–C1）・主題・練習時間を渡す → 5〜8分の英文（移転可能な语块3〜5個入り）または実在教材の音声・本文を受け取る → 盲听と大意1問 → 回答後に文本開示と誤り分類 → 跟读3〜5文（重音・连读・弱读・停顿）→ 文本を閉じて复述 → 新規3場面で主動使用 → 復盤 Markdown を出力、という順で回す。
- 負荷は素材長で決める。2〜3分素材なら30分（盲听3＋校准7＋跟读复述8＋主動提取7＋記録5）、5〜8分なら60分（盲听10＋校准15＋跟读复述15＋提取と記録20）。IELTS は Part 単位で分割し、Part 3/4 は2回に分ける。
- 復習は「明日の3問」と「3〜5ターンごとに旧语块をランダム再出題」。記録は Obsidian に YAML frontmatter（date / source / topic / level / listening_accuracy / retell_score）＋ 听错箇所（原句・听成・正确文本・原因）＋ 语块3つ ＋ 复述 ＋ 主動使用状況 ＋ 明日の3問。
- 上達は時間の堆積ではなく「音→意味→内在化」の通路づくり。ChatGPT は材料調達と反馈のコストを下げ、Obsidian は誤り・語块・進歩の軌跡を次回使える形で残す、という役割分担。

## 裏取り・注意点

- 本文は全文取得できた（9章・プロンプト2本・Markdown テンプレート込み）。ただし記事 URL 自体は未ログインだとログイン画面へリダイレクトされ、本文はローカルの取得経路でしか読めない。
- Obsidian は実在し、個人利用は無料・サインアップ不要（公式 pricing）。記事の復盤テンプレートが使う YAML frontmatter は Properties として標準機能で、プラグインを入れなくても動く。Sync は $4/月、Publish は $8/月、商用ライセンスは $50/年（いずれも任意）。
- 記事にはプラグイン名が一切出てこない（Dataview / Templater / Anki 等の名称は無い）。したがって「実在しないプラグインを実在のように書いた」という問題は無い反面、「Obsidian と連携」の実体は Markdown を手で貼る運用で、記事自身も「直接書き込めない場合は Markdown を出力」と留保している。
- ChatGPT から Obsidian への直接書き込みは、公式のコネクテッドアプリ一覧に Obsidian が無く、標準機能ではできない。MCP サーバーや第三者のプラグインを自分で用意する必要があり、記事の「如果你已经连接了 Obsidian」は前提を説明していない。
- ChatGPT Voice は実在するが、公式説明では「チャット内で応答テキストを表示したまま読み上げる」。つまり「第一遍は朗読だけ・テキスト非表示」はそのままでは成立せず、画面を隠す・別の読み上げに渡すなどの工夫が要る。テキスト応答から mp3 を書き出す機能も公式には確認できない。
- 「実在する音声素材を検索して直リンクを出させる」プロンプトについて: ChatGPT search は実在し引用付きで返すが、公式はリンク先の確認を求めている。音声ファイルの直リンクや再生可否は保証されず、リンク切れ・ペイウォール・幻覚リンクのリスクは残る（プロンプトで「编造しない」と書いても防げない）。
- 「初回60%・数回で80%」は著者の経験則で出典がない。研究側はむしろ高い被覆率を要求する（Nation 2006 は字幕なし理解に98%被覆・6,000〜7,000語族、van Zeeland & Schmitt 2012 は95%で十分と報告）。ただしこれは「字幕なしで理解する」ための語彙被覆の話で、記事の60%は「反復練習に使う素材の足切り」であり目的が違う。単純比較はできないが、記事の数値を研究の裏付けがあるようには読めない。
- 間隔反復の仕組みは記事には無い。あるのは「3〜5ターンごとに旧语块をランダム回收」と「明日の3問」だけで、間隔は固定またはランダム。Anki のような SRS を期待すると別物になる。
- EnglishPod は公式サイト englishpod.com が現在ドメイン販売ページ。ポッドキャスト自体は2013年に OpenLanguage へ移行して終了しており、入手は archive.org などの第三者アーカイブ頼み（権利関係は不明）。記事は「EnglishPod 那种长度」と長さの基準として挙げるだけで、入手元は示していない。
- BBC Learning English / VOA / TED-Ed 等を繰り返し再生する指示は私的利用の範囲だが、音声・文本の再配布は不可。記事は権利と利用条件に触れていない。
- 効果の定量データは無い。著者自身の学習歴（子供時代のテープ学習）と経験則が根拠で、この方法で伸びたという測定結果は示されていない。
- 中国語話者向けの内容（KK音標、赖世雄美语音标）。日本語話者がそのまま使うと発音教材の選択が変わる点に注意。
