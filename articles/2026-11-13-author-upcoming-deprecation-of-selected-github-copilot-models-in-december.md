# Upcoming deprecation of selected GitHub Copilot models in December

## テーマ

- GitHub Copilotの複数モデルについて、2026年12月14日に予定される廃止と推奨代替モデルを告知する記事。

## 著者の主張

- GitHubは、Copilot Chat、インライン編集、ask・agentモード、コード補完を含むCopilot体験全体で、Claude Fable 5、Claude Haiku 4.5、Gemini 3.8 Flash、Gemini 4 Argon、Grok 4.6、Kimi K3を2026年12月14日に廃止すると説明している。推奨代替は順にClaude Fable 5.2、Claude Haiku 5.5、Gemini 4 Hydrogen、Gemini 4 Carbon、Grok 4.7、Kimi K3は未定。代替への更新を案内し、Enterprise・Businessではモデル設定により代替モデルが自動有効化される場合があるとしている。

## 裏取り・注意点

- 廃止予定日とモデル一覧、例外および管理者向け設定の説明はGitHubの公式告知に基づく。Claude Haiku 4.5は年額プランの個人Copilot契約者には引き続き提供され、この廃止の対象外。代替モデルの自動有効化はグローバル既定値や管理者のモデルポリシー設定に依存する。
