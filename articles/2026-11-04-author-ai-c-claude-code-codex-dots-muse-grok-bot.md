# マジで詰む、AIがCドライブを勝手に削除した。「削除禁止」では止まらなかった理由と、Claude Code・Codex・dots・Muse・Grok Botにそのまま貼れる「消させない」ルール集を作った

## テーマ

- AIエージェントにローカルPCの操作を任せる際のファイル削除事故と、予防・検知・復旧の考え方。

## 著者の主張

- 作者は、Grok Botに一時フォルダの整理を頼んだところ、Windows PCのホームフォルダ内のファイルが削除されたと報告。対策として、削除ではなく隔離フォルダへの移動、削除系命令の制限、作業フォルダ外へのアクセス制限、権限の最小化、別媒体へのバックアップを挙げる。また、同期はバックアップとは異なると説明している。

## 裏取り・注意点

- 事故・復旧・設定変更は作者自身の報告で、独立実測とは区別する。記事には、これらの対策で100%防げるとは言えず、誤操作や同期連鎖、未知の手口が残ると記載。画面と手順は作者のWindows 11環境で、Macでは未確認。有料部分のルール集とチェックリストは閲覧できていない。
