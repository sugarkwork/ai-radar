# Axion 1.0: Open Agent Foundation Models, Simplified

## テーマ

- Axion 1.0のエージェント基盤モデルと、簡略化した学習レシピを扱う研究論文。

## 著者の主張

- 著者らは、2段階の教師ありファインチューニングと強化学習からなる3段階の学習を説明し、専用の中間学習、DPO、OPDを用いないと述べる。また、モデル重みだけでなくデータ構築・生成・フィルタリング・検証・プロンプト・学習コードを公開し、複数のエージェントベンチマークで強い性能を達成したと報告している。[arXiv論文](https://arxiv.org/abs/2611.03233)

## 裏取り・注意点

- arXiv掲載の概要で学習段階と公開対象を確認した。ベンチマーク性能は論文著者の報告として扱い、独立実測の結果とは区別する。
