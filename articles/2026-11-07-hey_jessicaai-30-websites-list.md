# 「違法っぽいけど合法」30サイトまとめの検証メモ

## テーマ

- 「30 Websites That Feel Illegal But Are Perfectly Legal」と題した、画像生成・動画・音声・文章・開発支援系のWebサービス30件のリスト。
- 各項目はURLと一行説明のみ。末尾は「Follow for more information」で、集客目的のリスト投稿。

## 著者の主張

- 30件すべてが無料または無料枠で使え、登録なしでも試せると読める構成。
- Raphael AI は「free unlimited」、Magnific は高画質アップスケール、SadTalker はOSSのトーキングヘッド、SoundCloud は「AI music tagging + recommendations」と説明。
- 具体的な利用手順・比較・検証結果は無い。

## 裏取り・注意点

- **30件すべてがカタログ未登録**だったが、Krea / Magnific / ElevenLabs / Suno / Runway / Cursor / Bolt.new / v0 / Replit / Perplexity / Claude など、広く知られた商用クローズドSaaSが大半。再現可能な配布物（repo・重み・プロンプト資産）は無い。
- **リンク切れ2件**: Phind（`www.phind.com` はボット遮断403、記載リンクは404）、Jasper（`jasper.ai/free` は404）。
- **説明と実体の不一致2件**: SoundCloud は音楽配信プラットフォームでAIタグ付けサービスではない。SadTalker のリンクは商用サイトで、OSS本体（OpenTalker/SadTalker）ではない。
- **Raphael AI**: 本文の `raphael.ai` は本環境から接続不能（20秒タイムアウト）。公式は `raphael.app`。無料は透かし入り・1024px上限・Fast約10クレジット/日＋低速キュー無制限、Pro $10/月（年払い）、公開APIなし。「free unlimited」は低速キュー限定の表現。
- **Magnific**（現Freepik、`magnific.ai` は `magnific.com` へ転送）: Premium $14.50/月（年払い、定価$20）。MCP・ComfyUI連携・APIあり。開発者向け接点はあるが商用SaaS。
- **Clipdrop**: 無料20回/24h、Pro $15/月、API従量課金。背景除去・アップスケール等で説明と一致。
- **Napkin AI**: 無料500クレジット/週、Plus $9、Pro $22。テキスト→図解。
- **Runway**: 投稿の「Gen-3 trial」は古い。2026-11-08時点の公式トップは Gen-4.5。
- その他（Krea、ElevenLabs、Suno、Kling AI、D-ID、Cursor、Bolt.new、v0、Replit、Gamma、Notion AI、Uizard、Perplexity、Otter.ai、OpusClip、Poe、remove.bg、cleanup.pictures、Claude、Hugging Face Spaces）は周知の商用サービス、またはプラットフォーム紹介で、個別の新規配布物ではない。
- **DeepSwap（顔交換）は deepfake 用途でリスク大**。カタログの対象外。
- 総括: 30件のうち新規の配布物は0件。リンク切れ2件、説明不一致2件、投稿全体が集客目的で一次検証なし。
