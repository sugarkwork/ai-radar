# OpenCode Browse

## 目的

- MCPサーバーとChromium拡張を通じて、AIエージェントが利用者の実ブラウザーを使えるようにする。

## 何ができるか

- 公式製品ページでは、Chrome、Edge、Brave、Arc、Helium、Vivaldi、Opera、Chromiumに対応すると説明されている。エージェントはバックグラウンドの折りたたまれたタブグループでタブを操作し、スクリーンショット、画面録画、ネットワーク通信のHAR記録を行える。ログイン、2FA、決済が必要なときはタブを利用者に引き渡し、利用者がContinueを押すと続行する。ツールバーから開いているタブをエージェントに渡す機能と、セッションごとにアクセス先サイトを制限する許可リストも案内されている。OpenCode、Claude Code、Cursor、Codex、ZedなどのMCPクライアントに対応すると記載されている。
