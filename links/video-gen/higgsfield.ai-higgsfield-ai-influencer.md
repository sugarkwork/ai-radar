# Higgsfield AI Influencer

## 目的

- 実在しない人物（AIインフルエンサー）の見た目と動きを、プロンプトではなくメニュー操作で組み立てるためのスタジオ。作った人物を element として保存し、縦動画の差し替え用キャラクターとして使い回す。

## 何ができるか

- キャラクタータイプは Average / Bold / Extreme の3種から選ぶ。顔写真のアップロードは任意で、アップロードした場合は顔の特徴を引き継ぐ。
- 髪型・髭・特徴などの項目を決めて Generate すると、クローズアップのポートレートと全身カットが出力される。
- 気に入った個体を element として保存し、以後の生成で参照として固定できる（顔が回ごとに drift するのを防ぐ用途）。
- 動きはトレンドのモーションを選ぶか、3〜30秒の動画をアップロードして指定する。動きの移植は Genjutsu が frame for frame で行う。
- 衣装・商品・場所だけを差し替えて、動きとカメラを保つ使い方も用意されている。
- 公式ページには「Your influencer, Now in ChatGPT」の導線があり、ChatGPT 側からもインフルエンサー生成を開始できる。

## 料金

- 無料枠: Free プラン（limited use、生成物に透かし）と Genjutsu の無料生成枠（pricing ページのカード表記「Higgsfield Genjutsu 5 free gens」）。有料: 月額サブスク＋クレジット制。2026-11-08 取得時点のカードは Starter 270 credits/月、Plus 1,200 credits/月、Ultra 3,000 credits/月。公式の価格解説ページ（2026年10月時点）は Starter $15/月 200 credits、Plus $49/月（年払い $39/月）1,000 credits、Ultra $129/月（年払い $99/月）3,000 credits。金額は地域と時期で変動し（2026年10月に $15/$49 → $19/$59 の変更が複数回）、取得時点の USD 額は一意に確定できない。税別。
- 無料の生成枠はプラットフォーム共通で、Genjutsu など一部機能に「free gens」が付く。クレジットは月次でリセットされ、翌月に繰り越されない。
- Unlimited と Free Generations は higgsfield.ai 上のみで、MCP / CLI / Canvas / Supercomputer からは使えないと pricing ページに明記されている。

## 登録の要否

- 要サインアップ。Web アカウントとクレジットが必須で、無料アカウントの生成物には透かしが入るため、投稿用途では有料プラン前提。API はプランのクレジットとは別の残高。
