# TailorRig — 衣装対応の自動リグ（SIGGRAPH Asia 2026）

## 目的

- キャラクターの身体スケルトンと衣装（スカート・髪・袖・アクセサリ）を同時に扱い、衣装まで含めたリグを自動生成する研究。
- 既存の自動リグ（UniRig など）が苦手な「身体の外側に独立して動く衣装パーツ」を、意味ラベルと補助骨格チェーンで扱う点が主題。

## 何ができるか

- ユーザー指定の身体スケルトンテンプレート（既存アニメ資産を再利用可能）と、`skirt` / `hair` / `sleeve` / `accessory` など補助10カテゴリの意味ラベルの2軸で制御。
- 自己回帰デコーダが、要求カテゴリの補助骨格チェーンだけを生成。
- skinning は chain-to-bone の階層重み付けで、隣接部位への weight bleeding を抑える。
- 評価用データセット **Human-Mix（38,088体、21クラス）** を新規構築。
