# 背景ガチャ（九龍城砦セット＋パース補助線）

## 目的

- 漫画・イラストの背景を、ブラウザ上で部品を組み合わせて作る無料ツール。3Dモデリングなしで、部屋・建物・街並みのラフを作る。

## 何ができるか

- 部屋150種類以上（旧表記120種類以上）に加え、住宅（日/米）・学校・洋館・中世の城・教会・九龍城砦のセットを追加。
- 九龍城砦は棟ごとに床高をずらして段を付ける実装で、積み重なった構造を再現できる。
- **パース補助線**: 書き出しの「下絵（なぞる用）」で、アイレベル線・パース補助線・消失点を別レイヤーに分離。
  - PSD: 「パース」フォルダ内の各レイヤー
  - SVG: 別ファイル
  - `vp.txt`: 消失点・アイレベルの画素座標（クリスタのパース定規合わせ用）
- 作った絵と GLB / FBX / OBJ は商用・非商用とも自由、クレジット任意。編集はブラウザ内で完結し、外部送信なし。
