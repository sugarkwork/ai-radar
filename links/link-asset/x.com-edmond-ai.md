# Edmond キャラクター三面図 — 同一人物を8方向で固定するAIペルソナ用リファレンス

## 目的

- AIで作った人物を毎回同じ見た目でショート動画に出すための、参照画像（キャラクターシート）の実例。1枚の中に全身の向きと顔の寄りを揃えてあり、画像生成・動画生成モデルに「この人物」を渡すときの入力として使う。
- 元ポストはフランス人風のAIペルソナ「Edmond」がpump.funで$EDMONDを出して失敗した事例の分析。この画像はそのペルソナの宣材として添付されたもので、手順の解説は無い。読む側は「同じ人物を角度違いで固定する資料はどう作られているか」の見本として使うのが実際的。

## 何ができるか

- 構成（実画像を確認）: 1200x1200の1枚。上段に全身5カット＝正面・斜め前・真横・斜め後・背面、下段にバストアップ3カット＝正面・左3/4・右3/4。背景は無地の薄いグレーで照明は均一、区切りは白い細線のみ。画像内に文字・ラベル・透かし・ロゴは一切ない。
- 被写体はオレンジのボウルカット、跳ねた口ひげ、茶系ツイードのスリーピース、柄ネクタイ、ポケットチーフ、茶の革靴という固定の意匠。全カットで髪型・ひげ・服・体格が一致しており、カット間の同一性が保たれている。
- 使い方の目安: 画像-to-画像の参照入力（同一人物の固定）にそのまま渡す。背面カットがあるため、ターンテーブル動画や3D化の下敷きにもなる（正面・斜めだけの資料では背面が破綻しやすい）。自前のキャラで同レイアウトを再現する場合は「character turnaround sheet, front / side / back view, full body + close-up, plain studio background」のような指定で、同じ5+3の構成を狙う。
- 同じ投稿にはTikTokプロフィールのスクリーンショットも添付されている（@ed_mondial、62.9K Followers / 2.3M Likes、固定3本が6.5M・5.5M・3.7M再生、bioにpump.funのコインリンク）。こちらは作例ではなく、ペルソナ運用の結果を示す画面。
