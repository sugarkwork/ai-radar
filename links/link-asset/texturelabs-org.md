# TextureLabs

## 目的

アート・デザイン向けの**無料テクスチャ素材庫**。壁・レンガ・コンクリート・金属・紙・空・土・水・布・フィルム・グランジなど、カテゴリ別に数千点を公開している。画像生成の背景素材、3Dのマテリアル、映像のオーバーレイ、合成の下地などに使う。

## 何ができるか

- カテゴリ別のブラウズ（Atmosphere / Brick / Concrete / Details / Fabric / Film / Glass / Grunge / Ink・Paint / Lens Effects / Metal / Paper / Sky / Soil / Stone / Vector / Water / Wood）。
- 各テクスチャは**複数サイズ**で配布。例: small 960px / med 1920px / large 4240px / x large 7952px のJPG。
- コレクション単位のまとめ（Borders、Grunge Masks、Halftones、Lens Light Effects、Shiny Foils、Vintage T-Shirt など）。
- 検索はテクスチャ／チュートリアル／ツールの3種を切り替え可能。
- チュートリアルとプラグイン（TextureLabs Tools）も併設。

## 料金

- **無料**。会員登録なしでダウンロードできる。
- 商用利用可（放送・映像・ゲーム・印刷・物販・広告など）。クレジット表記は不要（推奨はされている）。
- 出典: https://texturelabs.org/terms/（2026-11 時点）

## 登録の要否

- アカウント: 不要（`SIGN IN` は任意）
- APIキー: 不要

## 注意点

- **禁止されているのは「素材のまま再配布・販売」**。テクスチャパック、クリップアート、ストック画像、Photoshopテンプレートへの同梱、ストック3Dモデル用のテクスチャとしての配布は不可。
- 逆に、作品・動画・ゲーム・印刷物に**組み込んで**使うのは商用含めて自由。ゲーム内で使う場合も、売るのがゲーム本体なら問題ない（ゲーム制作テンプレートとして配るのは不可）。
- AI学習用データセットとしてまとめて再配布する用途は、上記の「再配布」に当たるため不可。
