# Supahero

## 目的

Web サイトのファーストビュー（ヒーローセクション）だけを集めた作例ライブラリ。

## 何ができるか

- 実在サイトのヒーロー部をスクリーンショットで一覧表示。各作例の個別ページ（`/hero/<slug>`）から元サイトへ飛べる。
- 例: Anubi、Better Stack、Zed、35mm、Wope、Treize grammes、Spectrum.Life など。
- 現在は **screensdesign に統合済み**（サイト上部に告知バナー。UX アプリライブラリへの導線）。

- 閲覧は無料。サイト内に料金ページは無い。
- 統合先の screensdesign は別サービスで、そちらの料金体系は本サイトからは確認できない＝未確認。
