# BestAIBuilder

## 目的

AI サイトビルダーを横並びで比較するためのランキングサイト。「同じブリーフで全ツールにサイトを作らせ、craft / speed / control / value で採点した」という前提を掲げ、101ツールを順位付けしている。

## 何ができるか

- 101ツールのスコア付き一覧（`/builders/<slug>` に個別レビュー）。
- 採点方法の公開（`/how-we-score`）。
- 上位の例: Modulify AI 94.6 / Lovable 88.6 / v0 by Vercel 87.3 / Framer 86.3 / Bolt 85.9 / Base44 84.7。下位は IONOS 59.6、Weebly 59.2、SITE123 58.3、Network Solutions 49.0。
- 週次の更新通知（メール）。

## 料金

- 閲覧は無料。料金ページは無い。
- サイトは「スポンサー枠なし・アフィリエイト順位の操作なし」と明記している（ただし広告・アフィリエイトが無いことの一次証明はできない＝未確認）。
