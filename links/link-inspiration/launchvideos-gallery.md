# Launch Videos Gallery

## 目的

X 上で共有されたプロダクトローンチ動画を日次で集めた作例ギャラリー。ローンチ動画の構成や演出を参考にするためのもの。

## 何ができるか

- ブランド別・人物別・カテゴリ別に動画を一覧できる（All Videos / Latest）。
- **Breakdowns** … 動画の構成を分解した解説ページ。
- **Opus 5.5 Prompts** … 動画生成モデル向けのプロンプト例をまとめたページ。
- 気になった動画を保存する機能（Saved）と、新着をメールで受け取るニュースレター。
- 動画の投稿（Submit Video）も受け付けている。
