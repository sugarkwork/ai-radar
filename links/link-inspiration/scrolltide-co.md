# Scrolltide

## 目的

スクロールに連動して動く「シネマティックなWebサイト」を作るための、プロンプトとテンプレートのライブラリ。プロンプトをコピーして AI（Claude / Cursor / Codex など）に貼り、サイトを生成させる使い方を想定している。

## 何ができるか

- 136本のテンプレート（Hero セクション、ランディングページ、3Dサイト、ダッシュボード／ウォレット／管理画面の UI スクリーン）。
- 70本のコンポーネント（3D のメディアギャラリー、円形スライダー、メッシュフロー、フォーカスリビール等）と、55本のアニメーション背景シェーダー（MP4・静止画・コードで提供）。
- 全テンプレートにソースコードが付属。React / Vite / Next.js / Tailwind / Framer Motion / GSAP / Three.js / WebGL / Lenis を前提にした構成。
- **MCP サーバー**を提供し、Claude / Cursor / Codex からライブラリを直接引ける（Yearly・Lifetime 限定）。
- 週次で新作が追加される（毎週金曜）。

## 料金

- Monthly: $39/月（通常 $59）。コアライブラリのみ。プレミアムテンプレートは週10件まで。
- Yearly: $144/年（月あたり $12、通常比 69% 減）。プレミアム無制限、3D・UI スクリーン・シェーダー・MCP が含まれる。
- Lifetime: $299 の買い切り（通常 $449）。Yearly と同内容を期限なしで。
- 個人利用とクライアント案件への利用は可。返金は不可（解約忘れの更新も対象外）。

## 登録の要否

- 必要。購入時にアカウントを作る。無料テンプレートは登録なしでコピーできる範囲があるが、ダウンロード導線の詳細は未確認。
