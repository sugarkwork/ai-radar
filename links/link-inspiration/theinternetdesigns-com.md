# The Internet Designs

## 目的

X（Twitter）と Pinterest に投稿された UI デザインを収集・索引化し、デザインの参考として引けるようにする。ポストの「find beautifully designed websites」に対応する。

## 何ができるか

- カテゴリ別の一覧: All、Interfaces、Landing page、Mobile apps、Dashboards、Interactions、Product、Typography、3D、Brand design、Logo design、Illustration。
- 各カードから元ポスト（x.com）または Pinterest のピンへ飛べる。動画付きの投稿はその場で再生される（`video.mp4`）。
- 検索（Ctrl+K）。新着順のフィード。
- 実装は GitHub で公開されている（iurvish/theinternetdesigns）。
