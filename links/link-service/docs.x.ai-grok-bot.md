# Grok Bot — 常駐するAIチーム（クラウド上の実コンピュータ）

## 目的

- xAI の常駐型 AI チーム。名前を付けた Bot がクラウド上の実コンピュータ（ブラウザ・ファイルシステム・ターミナル）を共有し、指示した仕事を継続して実行する。

## 何ができるか

- 各 Bot は自分のクラウドコンピュータでブラウザ・ファイル・ターミナルを使い、ノートPCを閉じても作業を続ける。
- Slack / Notion / Google Drive / Google Calendar / Gmail などのコネクタに加え、MCP や任意の API をカスタムツールとして接続できる。
- 複数の Bot が並列に動き、互いにメッセージやコンテキストを渡して分業できる。
- 一度手順を見せるとスキルとして保存し、決めたスケジュールで繰り返し実行（ルーティン）できる。
- デスクトップアプリと iOS / Android から同じ Bot に触れる。AI からは MCP / API のカスタムツールとして接続する形になる。

## 料金

- paid。X Subscription（Cursor）の Premium $30/月・Super $100/月・Ultra $200/月に含まれる。Teams は $30+/ユーザー/月。
- Free $0 と Plus $8/月 では利用できない。
- SuperGrok / SuperGrok Plus / SuperGrok Heavy / X Premium+ をリンクするか、Grok Business のシートでサインインしても使える。
- 利用量はプラン共通の週次プールから消費され、Super / Ultra ほど枠が大きい。

## 登録の要否

- 必要。X / Grok / Cursor のいずれかのアカウントでサインインし、対象プランかリンク済みサブスクリプションが必要。
- 対応 OS は macOS / Windows / Linux / iOS / Android。
