# Aura — プロンプトからHTMLを生成し、そのまま公開・書き出しできるAIウェブデザインツール

## 目的

- テキストプロンプトからランディングページやマルチページのウェブサイトを生成し、ブラウザ上で視覚編集して公開・書き出しまで完結させるサービス。公式は「AI landing page builder that creates stunning designs in seconds」と説明している。
- 生成物は独自形式ではなく、純粋なHTML・Tailwind CSS・vanilla JavaScript。ベンダーロックインを避けたいデザイナー、デザインをコードに落としたい開発者、デザイン未経験でLPが必要な人を対象に挙げている（learn/introduction）。

## 何ができるか

- プロンプトからのページ生成: コード生成モデル（Grok / GPT / Claude / Gemini系）を切り替えてHTMLを生成。料金ページの比較表にモデル名が列挙されている。
- @参照による文脈注入: テンプレート・コンポーネント・コードスニペットを @ で指定し、最大100,000文字（約2,000行）の文脈をプロンプトに追加できる。
- サイト構築: マルチページ、要素→ページのリンク、ページ遷移、CMS（コレクション/フィールド/アイテム、動的ページ）、サブドメイン公開、Pro以上でカスタムドメイン。
- 画像生成と素材: Nano Banana Pro / Flux 2 Pro / Ideogram 等による画像生成、4Kダウンロード、背景除去・アップスケール（プラン依存）。
- 書き出し: サイト全体をHTML/CSS/JSとしてエクスポートしてNetlify・Vercel等に設置、またはFigmaへレイヤー構造を保って書き出し。DESIGN.mdとプロンプト全文のコピーも可能。
- AIから使う形（MCP）: 公式リモートMCPサーバー https://mcp.aura.build/mcp をCodex・Claude Code・Cursor等に登録し、OAuth 2.1で認可すると、エージェントからCanvasの読み書き、HTML/Reactプロジェクトの取り込み、リビジョン単位の検証と公開、画像・動画の生成ができる。接続はStreamable HTTP、認可スコープは email/profile。認証なしのPOSTは401を返す。
- ブラウザのみでも全機能を利用可能。公開REST APIやCLIのドキュメントは確認できなかった（api.aura.build はサイトと同じHTMLを返すのみ）。
- 限界: AI生成はプロンプト数（月次上限またはクレジット）で制限される。Freeは2ページまで・個人利用のみ。生成品質そのものは未評価。

## 料金

- Free $0: AIプロンプト0（閲覧・テンプレートのリミックス・HTMLエクスポート・DESIGN.mdのコピーは可）、2ページ/プロジェクト、CMS 1コレクション、帯域1GB、個人利用のみ。
- トライアル: Pro/Max/Ultraは3日間・20プロンプト。支払い方法の登録が必要で、終了前のキャンセルなら課金なし。
- Pro $25/月（年払いプロモ $12.50/月 = $250/年）: 120プロンプト/月、100ページ、CMS全機能、カスタムドメイン、商用利用、HTML/Figma書き出し、チーム5名。
- Max $50/月（年払い $25/月 = $500/年）: 240プロンプト/月、帯域50GB、チーム10名。
- Ultra $100/月（年払い $50/月 = $1,000/年）: 560プロンプト/月、帯域100GB、チーム20名、優先サポート。
- Elite $200/月（年払い $100/月）: 1,080プロンプト/月（比較表にのみ掲載）。
- クレジット: 200クレジット $50 の一回払い（100/500もあり）。有効期限なし、1クレジット=1プロンプト、月次上限に達すると自動で使われる。クレジットだけではPro機能（Figma書き出し・Proテンプレート・商用利用）は解放されない。
- 未使用プロンプトは翌月に繰り越されない。支払いは主要クレジットカードとApple Pay、Stripe処理。年払い50%オフは期間限定のプロモ表示（2026-11-07時点）。

## 登録の要否

- アカウント必須。無料プランでも「Create Account」が必要で、クイックスタートも「サインイン→New Project」から始まる。
- AI生成を使うには3日トライアル（支払い方法の登録が必要）かクレジット購入が要る。FreeプランだけではAIプロンプトは0。
- MCPを使う場合もAuraアカウントでのOAuth認可が必要（クライアント側で `codex mcp add aura --url https://mcp.aura.build/mcp` → `codex mcp login aura --scopes email,profile` の例が公式ページに記載）。認可画面で要求権限を確認してから接続する。
- 商用利用はPro以上。Freeの成果物は個人利用に限られる。
