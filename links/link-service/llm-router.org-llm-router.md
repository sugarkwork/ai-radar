# LLM Router

## 目的

- GPT、Claude、Geminiなどのモデルを単一のAPIエンドポイント経由で利用するサービス。

## 何ができるか

- 公式ドキュメントではAnthropic互換のMessages APIとOpenAI互換のChat Completions API、現在利用できるモデルを取得するAPIを案内している。Claude CodeやOpenAI互換クライアントの接続例も掲載。利用にはアカウント作成とAPIキーが必要。

対応言語: 不明（確認資料に明記なし）。
日本語対応: 不明（確認資料に明記なし）。

## 料金

- 公式サイトの料金表はモデルごとの入力・出力トークン単価を掲載し、最低3ドルからの残高チャージを案内している。確認時点では無料トークン配布の案内は確認できなかった。

## 登録の要否

- 必要。公式サイトはメールアドレスとパスワードでのアカウント作成、およびAPIキー取得を案内している。
