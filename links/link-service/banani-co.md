# Banani

## 目的

テキストから UI を生成する AI デザインツール。プロンプトを「編集可能な UI デザイン」に変えることを狙う。ポストの説明（turn prompts into editable UI designs）と一致する。

## 何ができるか

- 文章で指示すると、複数画面のインタラクティブなプロトタイプを生成する（Web アプリ、モバイル、SaaS ダッシュボード、オンボーディング等）。
- Figma へ編集可能なレイヤーとして書き出し（オートレイアウト保持）。HTML/CSS 書き出しも有料プランで可能。
- **Banani MCP**: デザインを Claude Code / Cursor / Codex などのコーディングエージェントに直接渡し、そのスタックで実装させる。MCP は全プランで利用可能（アプリ内から接続コマンドを発行）。
- 参考アプリのリファレンス集（Pinterest / ChatGPT / Things 3 など）を公開。

## 料金

- Free: $0。クレジット制（月20／日次補充、JSON-LD の記載）。Figma 書き出しは1日3回まで。クレジットカード不要・期限なし。プライベートプロジェクトは無料でも可。
- Plus: $20/月、年払い $144（月あたり $12）。100クレジット/月、生成速度3倍、Figma/HTML 書き出し無制限。
- Pro: $50/月、年払い $360。クレジット無制限、最高速度、優先サポート。
- Enterprise: 個別見積（SSO、デザインシステム取り込み、カスタム統合）。
- 年払いは全有料プランで約40%安い、と FAQ に記載。クレジットは「エージェントが実際に使った分」で消費され、1生成で1クレジットとは限らない。

## 登録の要否

- 必要。`app.banani.co/auth/signup` からアカウント作成（無料プランはカード不要）。
- MCP 利用時はアプリ内で接続コマンドを実行する。
