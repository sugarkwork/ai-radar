# Mako UI

## 目的

HTML・CSS・JavaScriptでゲーム内UIを制作するミドルウェア。

## 何ができるか

Unity 6、Unreal Engine 5、Godot 4（alpha）、独自C++向け。Mako StudioとFigma同期を案内。
