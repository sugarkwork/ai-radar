# Pixel Art Lighter

## 目的

ピクセルアートのアルベド・法線・ライトマスクを生成編集し、点光源をリアルタイムに確認するブラウザツール。

## 何ができるか

PNG入出力とGodot4/Unity URP/GameMaker向け手順。単体HTMLを保存すればオフライン利用でき、CPUメインスレッドで処理する。

概要は2026-11-08の確認記録・紹介投稿に基づく。過去の数値はその確認時点のもので現在値としない。今回の実行確認はない。
