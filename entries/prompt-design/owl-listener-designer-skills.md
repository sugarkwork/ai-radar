# The Designer Skills Pack

## 出来ること

- デザインリサーチ、デザインシステム、UX戦略、UI、インタラクション、プロトタイピングとテスト、デザイン運用などに関するスキル、コマンド、プラグインを提供する。READMEには全体で273スキルと76コマンド、5コレクションとあり、このリポジトリのデザイン実務コレクションについては9プラグイン、111スキル、34コマンドと記載されている。

## 目的・背景

- AIエージェントが利用できる形式でデザインスキルをまとめたパック。READMEではClaude CodeとGemini CLI向けと説明している。

## 依存関係

- READMEに記載された利用先はClaude CodeとGemini CLI。その他の依存関係はREADMEから確認できない。

## 実行条件

- Claude Codeではマーケットプレイスを追加してDiscoverからコレクションを選ぶ手順が記載されている。Gemini CLIではプロジェクトルートでリポジトリをcloneし、拡張機能を.gemini/extensionsへコピーする手順が記載されている。

## 最短手順

- Claude Codeで「/plugin marketplace add Owl-Listener/designer-skills」を実行し、/pluginのDiscoverタブから必要なコレクションを選ぶ。特定プラグインを追加する例として「/plugin install ux-strategy@designer-skills」が示されている。
