# Anthropic's Prompt Engineering Interactive Tutorial

## 出来ること

- Claude向けのプロンプト設計を学べます。READMEは、基本構造、明確で直接的な指示、役割設定、データと指示の分離、出力形式、段階的な思考、例の活用、ハルシネーション回避、複雑な用途向けプロンプトを扱うと説明しています。9章のレッスンと演習があり、各レッスン末尾に例を試すExample Playgroundがあります。

## 目的・背景

- Claudeで効果的なプロンプトを設計する方法を、章の順に学び、演習で練習・トラブルシューティングするためのチュートリアルです。READMEでは学習目標として、プロンプトの基本構造、よくある失敗と対処技法、Claudeの長所と短所、一般的な用途のプロンプト作成を挙げています。

## 依存関係

- READMEはチュートリアルでClaude 3 Haikuを使用すると説明しています。ソフトウェア依存関係の一覧はREADMEに記載されていません。

## 実行条件

- READMEの案内では、リポジトリ内の「01_Basic Prompt Structure」から章の順に進めます。Google Sheets版とClaude for Sheets拡張機能を使う版も案内されています。

## 最短手順

- READMEの案内に従い、「01_Basic Prompt Structure」を開いて開始し、章の順にレッスンと演習を進めます。各レッスン末尾のExample Playgroundで例を試せます。
