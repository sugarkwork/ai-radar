# handraw-style

## 出来ること

- 手描きイラスト〜写実写真までの **365種の画風**（FA〜FI の分類番号と 001〜365 の通し番号）、**170種のレイアウト型**（SNSカード24 / データ infographic 38 / 漫画コマ割り71 / IP デザイン13 / EC 用24）、**36種の単色テーマ**を番号で選び、中英バイリンガルの画像生成プロンプトを出力する。
- 番号を指定しない「智能推薦」モードでは、主題から画風とテーマ色を自動で選び、推薦理由付きでプロンプトを出す。片方だけ指定すると、もう片方を補完する。
- 記事・動画のカバー画像設計: 全文や字幕から200字程度の要約と読者像を作り、画風と色を合わせてから出図する。動画カバーには視聴を促す指示を自動で足す。
- 長文記事の挿絵計画と Markdown への自動埋め戻し（全編で画風と色を統一）、撮影企画（10種類以上の撮影タイプ、3案の時空設定＋8宮格プロンプト）。
- Codex などのエージェントにリポジトリ URL を渡すだけでインストールされる Skill 形式。

## 目的・背景

「可愛く」「文艺に」といった曖昧な指示では画風が毎回ぶれる。画風・レイアウト・配色を番号で固定し、同じ番号を選べば同じ方向の絵が出るようにしたカタログ。README は、モデルごとの画風再現力の差を吸収するため、汎用モデルでは参照画像を併用する「兜底」設計を取ると説明している。

## 依存関係

- エージェント（Codex など）に Skill として読み込ませる。画像生成モデルは別途（任意のツールへプロンプトを貼る）。
- 動画制作・配音・絵コンテは別リポジトリ `handraw-video` に分離されており、この Skill には含まれない。

## 実行条件

- ライセンスは GitHub の判定で **NOASSERTION**。README は「自由に使用・改変・商用可。作者 yang0 とリポジトリ URL の保持を依頼」としており、OSI 標準ライセンスのファイルは置かれていない。再利用時はこの条件を確認する。
