# Awesome GPT Image 2.5 Prompts

## 出来ること

- READMEの説明では、OpenAI GPT Imageモデル向けの150件のプロンプトを9用途に分類し、投稿者名と元投稿へのリンクを付けて収録しています。プロンプト本文は投稿者が公開した原文のままで、用途別ファイルまたはdata/prompts.jsonから参照できます。

## 目的・背景

- 画像を作る目的に沿ってプロンプトを探せる、出典付きのプロンプト集です。READMEによると、収録プロンプトの多くはGPT Image 2.5の公開前に投稿されたもので、このリポジトリはそれらをGPT Image 2.5で実行したとは主張していません。

## 依存関係

- プロンプトの利用には画像生成モデルが必要です。READMEはOpenAIのGPT Imageモデルを対象として説明しています。各プロンプトの元投稿者・利用条件は個別に確認してください。

## 実行条件

- READMEでは、GPT Image 2.5は段階的に提供中で、すべてのアカウントで利用可能とは限らないと説明しています。プロンプトの56件には波括弧のテンプレート、さらに18件には大文字の角括弧プレースホルダーがあり、実行前に値を置き換えるよう案内しています。

対応言語: 不明（確認資料に明記なし）。

## 最短手順

- 用途別のプロンプトファイルを開き、使いたいプロンプト全文をコピーします。テンプレートの波括弧や角括弧の値を自分の内容に置き換え、必要に応じて主題・文言・配色を編集して画像生成モデルに入力します。
