# Generative AI for Beginners

## 出来ること

- 生成AIアプリ開発の基礎を21レッスンで学べる。レッスンには概念を説明するLearnと、概念およびコード例を扱うBuildがあり、コード例は可能な場合PythonとTypeScriptで提供される。各レッスンに追加学習用の資料もある。

## 目的・背景

- Microsoft Cloud Advocatesによる、生成AIアプリ開発の基礎を学ぶコース。各レッスンは個別のトピックを扱い、好きな順番で始められる。

## 依存関係

- コード実行には、対象レッスンに応じてAzure OpenAI Service、Microsoft Foundry Models、OpenAI API、またはFoundry Localを利用する。READMEはソフトウェアパッケージの依存関係を特定していない。

## 実行条件

- コード実行には上記いずれかのモデル提供手段が必要。PythonまたはTypeScriptの基本知識があると役立ち、リポジトリを自分のGitHubアカウントにforkすることも案内されている。Foundry Localについては、クラウド契約なしで端末上でオフライン実行できるとREADMEに記載されている。

## 最短手順

- コース設定レッスン（00-course-setup/README.md）で開発環境を準備し、21レッスンから学びたいトピックを選ぶ。コードを実行する場合は、選んだレッスンに対応するモデル提供手段を用意し、レッスンのコード例に進む。
