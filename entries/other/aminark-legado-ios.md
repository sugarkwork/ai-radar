# 小浣熊阅读

## 出来ること

- 阅读器支持阅读书源的 JSON、文件、URL、二维码导入，以及书源分组、编辑和调试；支持多书源并发搜索、缓存结果、书架管理、阅读排版、TXT/EPUB 本地阅读、系统朗读与 HTTP TTS 配置、RSS 订阅。README 提到搜索体验会受到网络和书源网站响应影响，复杂 JavaScript、登录、验证码和 WebView 规则可能存在平台差异。

## 目的・背景

- 作者说明，项目源于自己使用阅读器时觉得搜书等待较久、可用书源减少，希望改善搜书与书源导入体验，并开源分享。

## 依存関係

- README 未列出完整依赖清单。其说明从 v0.1.13 起，EPUB 阅读使用 Readium 显示无 DRM EPUB 2/3。

## 実行条件

- 安装支持 iOS/iPadOS 15.0 及以上。源码构建需要 macOS 和 Xcode。TestFlight 安装需在 iPhone 或 iPad 上安装 TestFlight；IPA 安装需要自行签名。

## 最短手順

- 准备有权使用的阅读书源，在「我的 → 书源管理」导入；在书架搜索书名或作者，打开书籍详情开始阅读。也可从书架或「我的 → 文件管理」导入本地 TXT/EPUB。
