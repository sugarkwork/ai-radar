# Blockbench

## 出来ること

- ローポリモデルとピクセルアートテクスチャを編集できる。モデルを標準形式に書き出して共有、レンダリング、3Dプリント、ゲームエンジンでの利用に使える。Minecraft Java EditionおよびBedrock Edition向けの形式にも対応し、プラグインで機能を拡張できる。
出典: https://github.com/JannisX11/blockbench

## 目的・背景

- 初心者向けのインターフェースと、経験豊富な3Dアーティスト向けのカスタマイズ機能・高度な機能を備えたモデルエディターとして説明されている。
出典: https://github.com/JannisX11/blockbench

## 依存関係

- ソースから起動する手順ではNode.jsをインストールし、npm installで依存関係を導入する。
出典: https://github.com/JannisX11/blockbench

## 実行条件

- README記載のソース起動手順はNode.jsとnpm installを前提とする。Electronでの開発起動はnpm run dev、ローカルWebアプリの起動はnpm run serve。
出典: https://github.com/JannisX11/blockbench

## 最短手順

- 最新版を利用する場合は公式サイトからアプリをダウンロードする。ソースから起動する場合はNode.jsを用意し、リポジトリでnpm installを実行後、Electronならnpm run dev、Webアプリならnpm run serveを実行する。
出典: https://github.com/JannisX11/blockbench
