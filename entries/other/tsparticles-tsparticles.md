# tsParticles

## 出来ること

- Webページ向けにパーティクルを作成するTypeScriptライブラリです。READMEではプリセットや各種フレームワーク用コンポーネントも案内されています。出典: https://github.com/tsparticles/tsparticles

## 目的・背景

- READMEは、Webサイトでの利用と particles.js からの移行を案内しています。出典: https://github.com/tsparticles/tsparticles

## 依存関係

- クイックスタートでは `@tsparticles/engine` と `@tsparticles/slim` を使います。機能に応じて必要なパッケージを追加します。READMEは「A lightweight TypeScript library for creating particles. Dependency free (*)」と説明しています。出典: https://github.com/tsparticles/tsparticles

## 実行条件

- READMEの例はJavaScriptのimportとasync処理を使い、ブラウザー向けにロードします。プラグインを使う設定では、該当するパッケージを先にロードする必要があります。出典: https://github.com/tsparticles/tsparticles

## 最短手順

- `@tsparticles/engine` と `@tsparticles/slim` を導入し、`loadSlim(tsParticles)` を一度実行してから `tsParticles.load(...)` に設定を渡します。READMEに背景色、移動有効化、粒子数を指定する例があります。出典: https://github.com/tsparticles/tsparticles
