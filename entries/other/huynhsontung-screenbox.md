# Screenbox

## 出来ること

- READMEによると、動画の再生、シークや音量変更のジェスチャー操作、ピクチャーインピクチャー、動画フレームの画像保存、Chromecast対応、ネットワーク上のメディアの閲覧・再生ができる。

## 目的・背景

- Windows向けのモダンなメディアプレーヤー。READMEは、幅広いデバイスでのパフォーマンスと使いやすさを重視すると説明している。

## 依存関係

- READMEによると、LibVLCSharpとUniversal Windows Platform（UWP）を基盤としている。

## 実行条件

- README記載の対応環境はWindows 10 version 1903以降、Windows 11、Xboxコンソール。開発時の前提条件はVisual Studio 2026とUWP開発ワークロード。

## 最短手順

- 利用者向けの推奨導入方法はMicrosoft Storeからのインストール。READMEにはwingetでの導入例として `winget install screenbox -s winget` も記載されている。
