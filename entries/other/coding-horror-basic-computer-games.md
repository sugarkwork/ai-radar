# BASIC Computer Games

## 出来ること

- 古典的なBASICゲームをC#、Java、JavaScript、Kotlin、Lua、Perl、Python、Ruby、Rust、VB.NETへ移植し、言語ごとの実装を学習・比較できます。READMEでは、元のプログラムの振る舞いを保ちつつ、大文字・小文字の入力対応やエラー処理など現代的な改善を加える方針が示されています。

## 目的・背景

- 書籍『BASIC Computer Games』のゲームを現代の言語へ移植し、プログラミング学習用の例として次の世代に引き継ぐプロジェクトです。READMEは、ゲームを新機能の追加よりも原作に忠実なシンプルな教材として扱うよう説明しています。

## 依存関係

- READMEには、各言語版の依存パッケージや外部ライブラリの指定はありません。

## 実行条件

- READMEによると、元のBASICコードはVintage BASIC（2009年頃）で動くよう調整されています。互換性の目安としてMicrosoft 8K Basic Rev 4.0が挙げられ、QBasicは後方互換性を保つ後発版として説明されています。個々の移植版の実行条件は言語・ゲームごとの資料を確認してください。

## 最短手順

- リポジトリで遊びたいゲームのフォルダーと言語別サブフォルダーを選び、そのゲーム固有のREADMEを確認して実行します。JavaScript版はREADME記載のブラウザー用ページから試せます。
