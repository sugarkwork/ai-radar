# awesome-quant

## 出来ること

- 定量ファイナンス（Quantitative Finance）向けのライブラリ・パッケージ・リソースを1ファイルに集めた curated list。Awesome バッジ付きで、現在も更新が続いている。
- 収録セクション: 数値計算とデータ構造 / 金融商品と価格計算 / テクニカル指標 / 売買とバックテスト / ポートフォリオ最適化とリスク分析 / 因子分析 / センチメントとオルタナデータ / 時系列 / 市場データとデータソース / 予測市場 / カレンダーと市場時間 / 可視化 / Excel・表計算連携 / 定量研究環境 / 多言語フレームワーク / 書籍と再現実装 / 商用サービス / アーカイブ済みプロジェクト / 関連リスト。
- 各項目に言語タグと一行説明、GitHub リンクが付き、初見でも「どれを使うか」を絞れる。
- 静的サイト版（GitHub Pages）も用意されている。

## 目的・背景

2015年から続く定番のリスト。個々のツールを紹介するのではなく、定量研究の工程ごとに選択肢を並べることで、車輪の再発明を避けるための地図として機能する。予測市場（Polymarket 等）の節があるなど、領域の変化も反映している。
