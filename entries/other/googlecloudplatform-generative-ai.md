# Generative AI on Google Cloud

## 出来ること

- Geminiのスターターノートブック、ユースケース、function calling、サンプルアプリを参照できます。RAGとGrounding、ImagenとVeoを使ったソリューション構築、Chirpを使った音声関連のサンプルも案内されています。

## 目的・背景

- Google Cloud上で生成AIワークフローを利用、開発、管理する方法を示すノートブック、コードサンプル、サンプルアプリなどをまとめたリポジトリです。READMEは、掲載コードをデモ目的とし、リポジトリ自体はGoogleの公式サポート製品ではないと説明しています。

## 依存関係

- READMEには、Gen AI Python SDKとノートブック環境のセットアップ案内があります。個々のサンプルの依存関係はREADMEから確認できません。

## 実行条件

- READMEはGoogle Cloud、Gen AI Python SDK、Google ColabまたはWorkbenchのノートブック環境をセットアップする案内を示しています。各サンプルに必要な具体的な実行条件はREADMEから確認できません。

## 最短手順

- READMEのsetup-env/にあるGoogle Cloud、Gen AI Python SDK、ColabまたはWorkbenchの環境セットアップ案内を参照し、目的に合うトピックのフォルダーからサンプルを選びます。個別サンプルの実行手順は各資料で確認してください。
