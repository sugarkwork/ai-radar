# Chroma.js

## 出来ること

- 色変換、色の明暗操作、カラースケール生成に使えるJavaScriptライブラリ。READMEにはLab/Lch補間、quantileやlogを含むdomain設定、Color Brewerスケールの例がある。出典: https://github.com/gka/chroma.js

## 目的・背景

- 色変換とカラースケールを扱うためのライブラリ。READMEはLab/Lch補間がRGBより見た目がよいと説明しているが、これはREADME上の説明であり、独立した評価結果は示されていない。出典: https://github.com/gka/chroma.js

## 依存関係

- READMEではzero-dependency JavaScript libraryと説明されている。出典: https://github.com/gka/chroma.js

## 実行条件

- Node.jsでも利用可能とREADMEに記載。具体的なNode.jsバージョン要件はREADMEに記載されていない。出典: https://github.com/gka/chroma.js

## 最短手順

- npm install chroma-jsで導入し、import chroma from "chroma-js";で読み込む。例: chroma('#D4F880').darken().hex()。出典: https://github.com/gka/chroma.js
