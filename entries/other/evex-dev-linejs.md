# LINEJS

## 出来ること

- LINE SelfBotを作成するJavaScriptライブラリ。READMEでは、Client、BaseClient、通話制御・メディア補助、Thrift読み書き、ストレージ、型定義などのパッケージを案内している。

## 目的・背景

- READMEは、LINE SelfBotを作成するためのJavaScriptライブラリとして紹介している。

## 依存関係

- Node.js 22.18以降または24.11以降、Bun、Denoに対応するとREADMEに記載。開発にはNode.js 22.18以降（または24.11以降）とpnpmが必要と記載。

## 実行条件

- TypeScript型定義を含む。ブラウザー利用については、READMEは https://esm.sh/@evex-dev/linejs の利用を案内している。

## 最短手順

- Node.js等では `npm install @evex-dev/linejs`、またはpnpm、yarn、Bun向けのREADME記載コマンドで導入する。Deno/JSR向けには `deno add jsr:@evex/linejs` などを案内している。
