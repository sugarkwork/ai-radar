# PlayCanvas Engine

## 出来ること

- WebGL2とWebGPUを基盤とするゲームエンジン。ブラウザーで動くインタラクティブな3Dアプリ、ゲーム、ビジュアライゼーションを作成できる。READMEにはグラフィックス、Gaussian Splatting、WebXR、物理演算、アニメーション、入力、音声、アセット配信、JavaScript/TypeScriptスクリプトの機能が記載されている。（公式README: https://github.com/playcanvas/engine）

## 目的・背景

- ブラウザー上で動作するインタラクティブな3Dコンテンツを作成するためのオープンソースゲームエンジン。（公式README: https://github.com/playcanvas/engine）

## 依存関係

- ローカル開発環境の構築にはNode.js 18以上が必要。READMEでは依存パッケージの導入に npm install を案内している。（公式README: https://github.com/playcanvas/engine）

## 実行条件

- Node.js 18以上。エンジンの利用例はブラウザーのcanvas上で実行するJavaScriptコード。（公式README: https://github.com/playcanvas/engine）

## 最短手順

- パッケージを利用する場合は npm install playcanvas。新規プロジェクトを作成する場合は npm create playcanvas@latest。READMEには Application、Entity、カメラ、ライトを使った最小コード例も掲載されている。（公式README: https://github.com/playcanvas/engine）
