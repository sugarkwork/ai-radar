# OpenAI Cookbook

## 出来ること

- OpenAI APIの一般的なタスクに取り組むためのサンプルコードとガイドを参照できます。READMEは、例の多くがPythonで書かれている一方、概念は他の言語にも適用できると説明しています。出典: https://github.com/openai/openai-cookbook

## 目的・背景

- OpenAI APIの利用方法を示すサンプルコードとガイドを集めたリポジトリです。出典: https://github.com/openai/openai-cookbook

## 依存関係

- READMEには、例を実行するにはOpenAIアカウントとAPIキーが必要と記載されています。個別の例が必要とする追加依存関係はREADMEから確認できません。出典: https://github.com/openai/openai-cookbook

## 実行条件

- READMEは、環境変数OPENAI_API_KEYにAPIキーを設定する方法を案内しています。また、多くの例はPythonで記述されています。出典: https://github.com/openai/openai-cookbook

## 最短手順

- OpenAIアカウントとAPIキーを用意し、READMEの案内に従ってOPENAI_API_KEY環境変数を設定して、対象のサンプルコードまたはガイドを参照してください。実行方法は個別の例に従います。出典: https://github.com/openai/openai-cookbook
