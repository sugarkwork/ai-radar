# PixiJS

## 出来ること

- WebGLおよびWebGPUレンダラー、アセット読み込み、マウス・マルチタッチ入力、テキスト描画、図形・SVG描画、テクスチャ、マスク、フィルター、ブレンドモードを備えるとREADMEに記載されています。出典: https://github.com/pixijs/pixijs

## 目的・背景

- READMEはPixiJSを、Web上でリッチなインタラクティブグラフィックスやクロスプラットフォームアプリケーションを作成するための2Dライブラリと説明しています。性能に関する最上級の表現は作者の説明であり、独立した実測として扱いません。出典: https://github.com/pixijs/pixijs

## 依存関係

- TypeScript 5ではWebGPU型のためにPixiJSが@webgpu/typesを追加し、追加設定は不要とREADMEに記載されています。TypeScript 6および7では、必要に応じて@types/webを使用し、@webgpu/typesをtypesから削除する手順が記載されています。出典: https://github.com/pixijs/pixijs

## 実行条件

- README記載の利用例はブラウザーのdocument.bodyとwindowを使います。WebGL/WebGPU対応状況など、具体的なブラウザー・端末要件は添付READMEでは確認できません。出典: https://github.com/pixijs/pixijs

## 最短手順

- 新規作成はnpm create pixi.js@latest、既存プロジェクトへの追加はnpm install pixi.jsとREADMEに記載されています。出典: https://github.com/pixijs/pixijs
