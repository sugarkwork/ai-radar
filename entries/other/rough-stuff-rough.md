# Rough.js

## 出来ること

- CanvasとSVGの両方で、線、曲線、円弧、多角形、円、楕円、SVGパスをスケッチ風に描画できる。塗りつぶしスタイルやroughness、bowingなどの指定もREADMEに記載されている。

## 目的・背景

- 図形をスケッチ風、手描き風のスタイルで描画するための小さなグラフィックスライブラリ。

## 依存関係

- READMEには依存パッケージの一覧や実行時依存関係の説明がない。

## 実行条件

- README記載の導入方法はnpmからのインストール、またはunpkgのバンドル版の利用。CanvasまたはSVGを使う例が掲載されている。

## 最短手順

- npm install --save roughjs で導入し、Canvasでは rough.canvas(canvas要素) を、SVGでは rough.svg(svg要素) を呼び出して描画する。例として rectangle の描画がREADMEに掲載されている。
