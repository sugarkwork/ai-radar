# Thaw

## 出来ること

- macOSのメニューバー項目を隠し、必要時に戻す、グループ化する、プロファイルを切り替える、レイアウトを変更する、Zen Modeを使う機能をREADMEが説明しています。項目をキー操作で探せるほか、thaw://リンク経由でRaycast、Floe、Shortcuts、シェルスクリプトから操作できると記載されています。

## 目的・背景

- READMEでは、不要なメニューバー項目を隠して必要なときに呼び出せるメニューバーマネージャーとして紹介されています。作者は無料、アカウント不要、トラッキングなしと説明しています。

## 依存関係

- READMEに具体的な依存ライブラリや外部サービスの必須条件は記載されていません。

## 実行条件

- README記載の対象はmacOSです。Thaw 2はmacOS 15〜26、Thaw 3 betaはmacOS 27向けとされています。

## 最短手順

- README記載のHomebrew手順: 安定版は `brew install thaw`。Thaw 3 betaは `brew install thaw@beta`。Thaw 2 stableは `brew install thaw-app/tap/thaw@2`、Thaw 2 betaは `brew install thaw-app/tap/thaw@2-beta`。またはGitHub Releasesのディスクイメージを取得してApplicationsへ移動します。
