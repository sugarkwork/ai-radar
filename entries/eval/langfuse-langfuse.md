# Langfuse

## 出来ること

- AIアプリのLLM呼び出し、検索、埋め込み、エージェントの動作などをトレースし、ログやユーザーセッションを調査・デバッグできる。プロンプトの管理・バージョン管理、LLM-as-a-judgeやコード評価などの評価、データセットと実験、メトリクス・ダッシュボード・アラート、モデルプロバイダー向けAI Gatewayを提供する。出典: https://github.com/langfuse/langfuse

## 目的・背景

- READMEでは、AIエージェントの評価と可観測性を含むオープンソースのAIエンジニアリング基盤と説明している。トレースや評価を通じてAIの利用状況を調べ、改善に使うことを目的としている。出典: https://github.com/langfuse/langfuse

## 実行条件

- セルフホストはDocker Compose、Kubernetes (Helm)、またはTerraformテンプレートによるデプロイ方法が案内されている。README掲載のDocker Compose手順はDocker Composeの実行環境を前提とする。出典: https://github.com/langfuse/langfuse

## 最短手順

- READMEの手順: `git clone --depth=1 https://github.com/langfuse/langfuse.git`、`cd langfuse`、`docker compose up`。出典: https://github.com/langfuse/langfuse
