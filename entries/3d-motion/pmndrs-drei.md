# @react-three/drei

## 出来ること

- @react-three/fiber向けのヘルパーおよび機能を備えた抽象化コンポーネントを提供する。READMEにはカメラ、操作コントロール、ローダー、シェーダー、パフォーマンス関連コンポーネントなどが掲載されている。出典: https://github.com/pmndrs/drei

## 目的・背景

- 汎用的に役立つコンポーネントを集めたライブラリ。READMEでは、他の利用者にも有用な汎用コンポーネントのコントリビューションを案内している。出典: https://github.com/pmndrs/drei

## 依存関係

- READMEによると、three.jsのexamples/jsmではなく、独立したthree-stdlibを使用する。出典: https://github.com/pmndrs/drei

## 実行条件

- README記載の利用対象は@react-three/fiber。Web向けの既定エクスポートはHtmlとLoaderを含み、React Native向けの@react-three/drei/nativeはHtmlとLoaderをエクスポートしない。READMEにはnpm install @react-three/dreiによる導入例がある。出典: https://github.com/pmndrs/drei

## 最短手順

- npm install @react-three/dreiで導入し、Reactコードから@react-three/dreiをimportする。React Nativeでは@react-three/drei/nativeからimportする。出典: https://github.com/pmndrs/drei
