# Material Painter

## 出来ること

- 3DモデルのPBRテクスチャをレイヤーとマスクで編集し、ローカルMCPからアプリ機能を呼び出せる。

## 目的・背景

- Rustとwgpuを使った3Dテクスチャ制作ツール。

## 依存関係

- ソースビルドにはstable Rust。GUIはeframeなどを使用。

## 実行条件

- 公式READMEではx64 Windows 10/11またはx64 Linux、DirectX 12またはVulkan。

## 最短手順

- 配布ページとREADMEを参照し、アプリ設定でローカルMCPを有効にして表示されたURLをクライアントに設定する。
