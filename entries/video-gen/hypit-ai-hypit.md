# hypit

## 出来ること

- エージェント（Claude Code、Codex など）に**動画編集の言語と実行系**を与える。参照動画を投入すると、映像・字幕・Bロール・エフェクトをひとつのワークフローとして複製する。
- タイミングを秒ではなく**語（ワード）にアンカー**する独自のマークアップ（SVML）で記述するため、尺が変わっても字幕と演出の対応が崩れにくい。
- 1コマンドで100本のバリエーションを書き出す運用を想定（顔・文言・Bロールの差し替え）。
- 生成モデルは必須ではない。字幕・モーショングラフィックス・コード描画の素材だけをコンパイルして動画にすることもでき、その場合は生成サービスの課金が発生しない。
- テンプレートから始める／自然言語でワークフローを書かせることもでき、参照動画の複製は入口のひとつという位置づけ。

## 目的・背景

ショート動画の「型」を、職人の手作業ではなく再現可能なソースとして扱う発想。SVML のソースとレンダリング結果を並べたプレビューがREADMEに掲載されている。Trendshift の TypeScript デイリー1位を取得。

## 依存関係

- Node.js 22.15 以上（リポジトリの開発には pnpm 10.33 / TypeScript 5.9）。
- 生成モデルを使う場合はモデルサービスの契約が別途必要。既定の推奨はホスト型の HypiHub だが、自前APIやローカルモデルも指定できる。
- パッケージ版 0.3.2 で Bach 1.0 Pro（bach.art）のモデル定義 `@hypit/bach` が既定の依存に加わった。0.3.0 から上げる場合はマイグレーションガイド（リポジトリの `migrations/0.3.1.md`）に沿って SDK の import と依存を更新する。
- 動画の書き出しは ffmpeg ベース。

## 実行条件

- **ライセンスは Apache-2.0 の改変版**。自組織内の商用利用・受託業務での利用は可。ただし (a) マルチテナント環境での提供（2社以上が別ワークスペースを持つ形。無償でも該当）、(b) 商用目的での再配布・販売は、書面での商用ライセンスが必要。CLIやレポート上のロゴ・著作権表示の削除も不可。生成物の権利は利用者に帰属する。
- 参照動画の複製・顔差し替えは、肖像権・著作権・プラットフォーム規約の確認が前提。
- ツール自体は無料。エージェントとモデルサービスの利用料は別。

## 最短手順

```bash
npx skills add hypit-ai/hypit -g    # スキルとして導入（初回利用時に実行系を準備）
```

導入後はエージェントに参照動画を渡すか、作りたい動画を説明してワークフローを書かせる。
