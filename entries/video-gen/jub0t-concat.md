# Concat

## 出来ること

マルチトラック編集、字幕、音声合成、背景除去、キーフレーム、4K書き出し。JSON-RPCやMCPでも操作できる。

## 目的・背景

ローカル優先のクロスプラットフォーム動画エディタ。作者は透かし・アカウント・アップロード不要と説明する。

## 依存関係

Rust製エンジン。字幕・音声・背景除去のモデルは初回ダウンロードが必要。

## 実行条件

macOS / Windows / Linux / Android。ベータ版。環境ごとの対応は配布元を確認。

## 最短手順

公式リリースから対応プラットフォームのビルドを取得し、必要なAIモデルを設定で導入する。

AGPL-3.0。モデルには別ライセンスの可能性がある。オフライン動作や4K出力は当方未検証。 実行・品質は未検証。
