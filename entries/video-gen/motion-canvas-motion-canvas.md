# Motion Canvas

## 出来ること

- TypeScriptのジェネレーターを使ってアニメーションを作成し、エディタでリアルタイムプレビューできる。情報提示向けのベクターアニメーションを制作し、ナレーションと同期できる。出典: https://github.com/motion-canvas/motion-canvas README

## 目的・背景

- プレビューに加え、アニメーションの一部を編集でき、手間のかかる調整を行えるようにする専用ツール。出典: https://github.com/motion-canvas/motion-canvas README

## 依存関係

- README記載の開発時依存・構成要素は、npm、Lerna、Viteと、モノレポ内の各パッケージ（2d、core、create、docs、e2e、examples、internal、player、template、ui、vite-plugin）。個別の利用条件やバージョン要件はREADMEに記載されていない。出典: https://github.com/motion-canvas/motion-canvas README

## 実行条件

- ローカル開発では、リポジトリを取得後、ルートで `npm install` を実行し、`npx lerna run build` で全パッケージをビルドする手順が記載されている。エディタ開発では `npm run template:dev` を実行する。出典: https://github.com/motion-canvas/motion-canvas README

## 最短手順

- READMEのGetting Startedガイドを参照する。ローカル開発の場合は、ルートで `npm install`、続いて `npx lerna run build` を実行する。出典: https://github.com/motion-canvas/motion-canvas README
