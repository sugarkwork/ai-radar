# Modern Web Guidance

## 出来ること

- コーディングエージェント向けに、現代のWebプラットフォーム機能やベストプラクティス、ブラウザー互換性データを含むガイドを提供します。READMEには、ガイドの検索・ID指定での取得・コードベースの旧式パターンのスキャン機能が記載されています。対象分野としてCSSレイアウト、パフォーマンス、フォームとUI、アクセシビリティ、組み込みAIなどが挙げられています。出典: https://github.com/GoogleChrome/modern-web-guidance

## 目的・背景

- READMEは、エージェントが学習データに多い旧式の実装を提案しがちな課題に対し、専門家が選定したガイドをエージェントのコンテキストに提供することを目的として説明しています。モダンなブラウザーAPI、パフォーマンスとアクセシビリティ、軽量なフォールバックを扱うとしています。これらはREADMEに記載された目的・説明であり、独立した効果測定ではありません。出典: https://github.com/GoogleChrome/modern-web-guidance

## 依存関係

- READMEのクイックスタートと試用例は `npx modern-web-guidance@latest` を使用します。具体的な実行時依存パッケージやバージョン要件は、添付READMEでは確認できません。出典: https://github.com/GoogleChrome/modern-web-guidance

## 実行条件

- README記載のCLIコマンドを実行するには、`npx` を利用できる環境が必要です。OS、Node.jsのバージョン、ネットワーク要件などの詳細は、添付READMEでは確認できません。出典: https://github.com/GoogleChrome/modern-web-guidance

## 最短手順

- READMEのクイックスタートは `npx modern-web-guidance@latest install` です。対話式ウィザードでインストールすると説明されています。インストールせずに試すコマンドとして、`npx modern-web-guidance@latest search "animate a dialog modal backdrop"`、`npx modern-web-guidance@latest retrieve "animate-to-from-top-layer"`、`npx modern-web-guidance@latest legacy-scan .` が記載されています。出典: https://github.com/GoogleChrome/modern-web-guidance
