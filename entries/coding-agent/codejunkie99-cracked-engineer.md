# Cracked Engineer

## 出来ること

- 設計上の決定を `SYSTEM.md` のルールにし、各ルールについて故障を仕込んだテストを作る Claude Code skill。READMEには intake、audit、change、incident の4モードが記載されています。出典: https://github.com/codejunkie99/cracked-engineer

## 目的・背景

- READMEは「the agent design before it codes」と説明し、設計をテストで失敗させられる形にして、セッションをまたいでも設計を保つことを目指しています。出典: https://github.com/codejunkie99/cracked-engineer

## 依存関係

- README記載のインストールスクリプトには git と Node.js 18以降が必要です。出典: https://github.com/codejunkie99/cracked-engineer

## 実行条件

- README記載の対象は Claude Code skill です。全プロジェクトで使う場合は `~/.claude/skills/cracked-engineer/` に、単一リポジトリで使う場合はその中の `.claude/skills/cracked-engineer/` に配置します。出典: https://github.com/codejunkie99/cracked-engineer

## 最短手順

- フォルダを所定の Claude skills ディレクトリへコピーし、Claude Codeで `/cracked-engineer` を実行します。リポジトリ内ではskillがインストールスクリプトを一度実行するとREADMEに記載されています。出典: https://github.com/codejunkie99/cracked-engineer
