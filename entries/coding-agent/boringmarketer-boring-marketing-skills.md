# Boring Marketing Skills

## 出来ること

- Claude Code、Codex、Cursorなどのエージェントに追加する32種類のマーケティングスキルを提供。地域ビジネス向けの調査、ポジショニング、コピー、ページ作成、SEO、AI検索、広告、メール、コンテンツ制作などを扱います。READMEでは各スキルが有料ツールなしで動くと説明しています。

## 目的・背景

- READMEによると、作者は実際のキャンペーンからスキルを作成し、顧客の調査やマーケティング作業をエージェントで支援することを目的としています。成果に関する記述は作者の報告です。

## 依存関係

- READMEはエージェント自身のウェブアクセスで各スキルを利用できると説明しています。追加ツールとしてExa、Firecrawl、DataForSEO、画像・動画生成サービス、広告APIなどを紹介し、無料利用枠や有料プランの有無を記載しています。すべてのスキルにこれらの追加ツールが必要という説明はありません。

## 実行条件

- Claude Code、Codex、Cursorなどのエージェントを対象としています。READMEは全スキルが有料ツールなしで動作すると説明しています。一部の追加連携にはアカウントやAPIキー、利用プランが必要となる場合があります。

## 最短手順

- 対応エージェントでは `npx skills add boringmarketer/boring-marketing-skills` を実行して導入します。Claude Codeは `/plugin marketplace add boringmarketer/boring-marketing-skills`、続けて `/plugin install boring-marketing@boring-marketing-skills` で導入できます。導入後に `/start-here` を入力し、対象ビジネスを指定します。
