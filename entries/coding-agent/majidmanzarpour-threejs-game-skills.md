# Three.js Game Skills

## 出来ること

- CodexとClaude Code向けの共有スキル群を使い、Three.jsのブラウザーゲーム制作を支援する。ディレクタースキルがゲームプレイ、グラフィックス、UI、アセット生成、音声、デバッグ、リリース検証を適宜振り分ける。ゲーム用の雛形、決定論的テストフック、seed付き乱数、Playwrightのテストテンプレートも同梱するとREADMEは説明している。

## 目的・背景

- 利用者が個々の専門スキルを毎回選ばなくても、ディレクターが依頼の範囲とアートディレクションを保ちながら関連スキルを使う構成。READMEでは、変更規模に応じて検証範囲を調整すると説明している。

## 依存関係

- 同梱スキルの利用に特定のモデルや有料APIキーは必須ではないとREADMEに記載。外部のモデル・画像・音声生成を利用する場合は、Tripo、Gemini、ElevenLabsのAPIキーを任意で設定できる。

## 実行条件

- スキルをCodexまたはClaude Codeにインストールして利用する。READMEにはskills CLIを使う方法と、クローンしたチェックアウトからinstall.shを使う方法が記載されている。

## 最短手順

- Codexの場合は `npx skills add majidmanzarpour/threejs-game-skills --skill '*' -a codex -g -y` で全スキルをインストールし、CodexでThree.jsゲームの作業フォルダーを開いて `threejs-game-director` を指定する。
