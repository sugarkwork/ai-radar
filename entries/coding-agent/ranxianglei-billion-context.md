# billion-context

## 出来ること

長い会話の履歴を階層的に圧縮し、コーディングエージェントのコンテキストを管理する。

## 目的・背景

作者は5倍のトークン節約、月単位セッション、95–97%のキャッシュヒットを主張。提供データは条件依存であり一般保証ではない。

## 依存関係

Node.jsと対応エージェント。モデルやAPI接続の費用は別。

## 実行条件

利用先のエージェントやモデルに応じてセットアップが異なる。圧縮により重要情報を失う可能性がある。

## 最短手順

READMEの対応環境と導入方法を確認し、重要事項の保持を自身のタスクで評価する。
