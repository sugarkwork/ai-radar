# Dashi PPT Skill

## 出来ること

- READMEによると、AIエージェントでプレゼン資料を生成し、ブラウザー上でテキスト、画像、レイアウト、配色などを編集できます。HTMLオフラインパッケージ、PDF、編集可能なPPTXへの出力に対応すると説明されています。出典: https://github.com/chuspeeism/dashi-ppt-skill

## 目的・背景

- 職場で使うプレゼン資料を、構造と視覚スタイルを揃えて作成し、生成後も編集できるようにすることを目的としています。READMEは、ピクセル単位の手作業によるカスタムデザインには不向きとしています。出典: https://github.com/chuspeeism/dashi-ppt-skill

## 依存関係

- README記載の環境要件はNode.js 20以上とnpmです。PPTXまたはPDFの出力にはChrome、Chromium、またはEdgeが必要です。初回生成時にnpmが依存関係をインストールすると説明されています。出典: https://github.com/chuspeeism/dashi-ppt-skill

## 実行条件

- READMEではClaude Code、Codex、豆包、Marvis、Workbuddy、Dumate、Qclawを対応プラットフォームとして列挙しています。Cursorなどのローカルエージェントは、ファイルの読み書きとシェルコマンドの実行が必要とされています。出典: https://github.com/chuspeeism/dashi-ppt-skill

## 最短手順

- README記載のインストール・更新コマンドは `npx dashi-ppt-skill@latest` です。インストール後、エージェントに資料のテーマ、対象読者、ページ数、強調点を伝え、テーマを選択して生成・編集し、必要な形式に出力します。出典: https://github.com/chuspeeism/dashi-ppt-skill
