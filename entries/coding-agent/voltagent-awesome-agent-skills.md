# Awesome Agent Skills — コーディングエージェント向けスキルの索引

## 出来ること

- 開発チームやコミュニティが公開するスキルを探せる。READMEには、例えばフロントエンド設計や生成アートのスキルが掲載されている。

## 目的・背景

- 公開スキルの概要とリンクをまとめたカタログ。用途に合うスキルの選定に使える。

## 依存関係

- カタログはGitHub上で閲覧できる。選んだスキルの導入方法、追加ツール、ライセンスや料金は配布元で確認する。カタログのMITライセンスと掲載先の利用条件は別々に扱う。

## 実行条件

- 選んだスキルを読み込めるエージェントが必要。READMEはCodexやClaude Codeなどの対応クライアントと配置先を案内している。

## 最短手順

- READMEから用途に合う項目を1件選び、配布元でスキルの指示、依存関係、利用条件を確認する。
- 利用するエージェントの手順に従ってそのスキルを導入し、エージェントへの依頼でスキル名を明示して、対象のタスクに使うよう指示する。
