# Claude Code Frontend Design Toolkit — フロントエンド設計向けのスキル・MCPガイド

## 出来ること

- UIのデザイン方針、配色・タイポグラフィ、アニメーション、アクセシビリティ、Figma連携など、作業に応じてClaude Code向けのスキルやMCPサーバーを探せる。READMEは各ツールへの索引として使う。

## 目的・背景

- 著者は、似通いがちな生成UIの改善を目的に、デザイン方針の決定から実装後の調整までの手順を整理している。見た目の改善は著者の説明であり、比較実測は行っていない。

## 依存関係

- READMEの閲覧は公開GitHubページで可能。掲載スキルの利用にはClaude Codeと選んだスキルの導入が必要。READMEのFigmaデスクトップMCPの例では、Figmaデスクトップアプリと対象シートが必要とされる。

## 実行条件

- 設定例は選んだツールごとに適用する。必要なアカウント、権限、料金、ライセンスは各配布元の条件に従う。確認したGitHub Releasesページに公開リリースの表示はなかった。

## 最短手順

- READMEのDesign SkillsからFrontend Designの配布元を開き、配布元の手順でClaude Codeに導入する。対象プロジェクトでClaude Codeを開き、たとえば「音楽配信サービスのダッシュボードを作って」と入力する。配布元のREADMEでは、フロントエンド作業の依頼時にスキルが自動で使われると説明している。
