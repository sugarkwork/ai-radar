# Claude Repurpose

## 出来ること

- READMEによると、YouTube動画、ブログ記事、ポッドキャスト、ローカルファイルなどを入力し、X、Threads、LinkedIn、Instagram、TikTokなどの投稿案、ニュースレター、記事案、SEOメタデータ、7日間の配信カレンダーを生成します。READMEは30以上のファイルをプラットフォーム別に出力すると説明しています。

## 依存関係

- 必須要件としてClaude Code CLIとPython 3.10以上が記載されています。YouTubeの文字起こし抽出用のyt-dlp、音声の文字起こし用のWhisper、画像生成用の/bananaは任意要件です。
