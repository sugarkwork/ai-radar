# AGENTS.mdでコーディングエージェントにプロジェクトの作業手順を渡す

## 出来ること

- ビルドやテストの手順、コード規約をリポジトリ内に記述し、対応エージェントの作業コンテキストとして渡せる。公式サイトはサブプロジェクト別のファイル配置も案内している。

## 目的・背景

- エージェントがプロジェクト固有の手順を参照できるようにする。公開研究では、評価条件全体でタスク成功率は一般に改善せず、推論コストは平均で20%超増加したと報告されている。

## 依存関係

- ファイルは標準Markdownで、必須フィールドはない。利用にはファイルを読み込めるエージェントが必要で、公式サイトにはAiderとGemini CLIの設定例がある。

## 実行条件

- 指示の読み込みとコマンド実行はエージェント側が担う。READMEのpnpm手順は、同梱のNext.js公式サイトをローカルで起動する場合に使う。リポジトリはMITライセンスで、エージェントの利用条件や料金は製品ごとに異なる。

## 最短手順

- 対象リポジトリのルートにAGENTS.mdを置き、そのプロジェクトで使うテストコマンドと適用範囲を短く書く。
- 対応エージェントを対象リポジトリで起動し、『変更やコマンド実行はせず、このリポジトリのテスト手順と参照元を教えて』と依頼する。回答をAGENTS.mdと照合してから作業に使う。
