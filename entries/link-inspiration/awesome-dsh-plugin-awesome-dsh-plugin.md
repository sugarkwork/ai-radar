# Awesome DeepSeek Harness (DSH) Plugin

## 出来ること

- DeepSeek Harness用プラグインをカテゴリ別に掲載し、説明や導入コマンドから候補を探せます。READMEによると、dsh 0.2.1以降ではプラグイン一覧をインデックスソースとして追加でき、Discoverタブとplugin_marketエージェントツールから同じエントリーを検索できます。出典: https://raw.githubusercontent.com/awesome-dsh-plugin/awesome-dsh-plugin/main/README.md

## 目的・背景

- DeepSeek Harness向けコミュニティプラグインを一覧化し、選択と導入を助けるキュレーションリストです。READMEは、各掲載について機能説明・カテゴリ・メンテナンス状況を確認すると説明しています。出典: https://raw.githubusercontent.com/awesome-dsh-plugin/awesome-dsh-plugin/main/README.md

## 依存関係

- 一覧を読むだけなら特定の実行環境は示されていません。インデックスソース機能はdsh 0.2.1以降が必要です。個々のプラグインの依存関係は各掲載内容および配布元で確認してください。出典: https://raw.githubusercontent.com/awesome-dsh-plugin/awesome-dsh-plugin/main/README.md

## 実行条件

- このリポジトリ自体はプラグインカタログです。掲載プラグインの導入・実行条件はそれぞれ異なります。READMEは第三者プラグインが利用者権限で動作し、ファイル、認証情報、ネットワークにアクセスしうると注意しています。出典: https://raw.githubusercontent.com/awesome-dsh-plugin/awesome-dsh-plugin/main/README.md

- README記載の方法では、dsh 0.2.1以降のPlugins → Discover → Index sourcesで https://cdn.jsdelivr.net/npm/dsh-plugin-catalog/index.json を追加します。インデックス掲載外のGitHub配布物は、READMEに示された個別の導入コマンドと配布元の説明を確認してください。出典: https://raw.githubusercontent.com/awesome-dsh-plugin/awesome-dsh-plugin/main/README.md
