# Cubicle

## 出来ること

- AIエージェントの状態やタスクをピクセルアートのオフィスで表示する。READMEではPaperclip、Claude Code、Codex CLI、Gemini CLIへの対応と、JSONフィード経由で他のツールを接続できることを説明している。待機中のエージェントへの応答やチャット、タスク・失敗した実行の表示、通知、テーマ変更なども機能として記載されている。

## 目的・背景

- AIエージェントの作業状況を、机での作業やラウンジでの待機などの視覚表現で把握するためのライブオフィス。

## 依存関係

- READMEは依存関係ゼロと説明している。

## 実行条件

- README記載の必要条件はNode.js 18以降。

## 最短手順

- Node.js 18以降の環境で `npx @caglarutkuguler/cubicle` を実行し、表示されたアドレスをブラウザーで開く。Claude Codeプラグインとして使う場合の手順はREADMEに別途記載されている。
