# AI Agents for Beginners

## 出来ること

- AIエージェント構築の基礎を学べるコースです。READMEは各レッスンに解説、短い動画、Pythonコード例、追加学習資料が含まれると説明しています。

## 目的・背景

- AIエージェントを作り始めるための知識を教えるコースです。レッスンごとにテーマが分かれており、好きなレッスンから始められます。

## 依存関係

- コード例はMicrosoft Agent FrameworkとMicrosoft Foundry Agent Service V2を利用します。一部のコード例はMiniMaxなどのOpenAI互換プロバイダーにも対応するとREADMEに記載されています。

## 実行条件

- READMEではMicrosoft FoundryにAzureアカウントが必要としています。コード例の設定方法はリポジトリ内のCourse Setupを参照するよう案内されています。

## 最短手順

- 学びたいレッスンのREADMEを開いて解説を読み、対応する短い動画とcode_samples内のコード例を確認します。コード例を実行する場合は、Course Setupの設定手順を確認してください。
