# unslop

## 出来ること

- **「AIが作ったようなUI」を、設計されたUIに直す** Claude Code / Codex 向けスキル。
- まず「どこがAI生成っぽいか」を特定し、そのプロダクトに合ったデザイン方向を決めてから手を入れる（いきなり書き換えない）。
- 余白・配色・アイコン・フォント・レイアウトを分けて調整し、**機能とコンテンツ構造は維持する**。製品画像やグラフも対象に含める。
- 既に出来が良いページには「小さく直す」提案で止める。

## 目的・背景

2026-10-29 公開、4日で ★7,554。紫のグラデーション・大きなカード・光るボタンという「AI製テンプレの見た目」が量産されていることへの対抗として作られた。方向性を先に決める設計判断を、スキルとして固定している点が特徴。

## 依存関係

- Claude Code または Codex
- 対象プロジェクトのフロントエンド（HTML/CSS/JS、React 等）

## 実行条件

- スキルのみ（外部APIなし）。
- 対象リポジトリのスタイル規約がある場合は、そちらを優先するよう指示する必要がある。

## 最短手順

```text
スキルを導入し、対象ページを指定して実行（README 参照）
```
