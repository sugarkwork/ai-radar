# LangGraph

## 出来ること

- 長時間実行するstatefulなエージェントやワークフローの構築、管理、デプロイを支援する。READMEは、耐障害性を備えた実行と中断後の再開、人間による状態の確認・変更、短期・長期メモリを機能として説明している。実行の可視化やデプロイにはLangSmith関連製品も案内されている。出典: https://github.com/langchain-ai/langgraph
