# Flowise

## 出来ること

- 視覚的にAIエージェントを構築する。READMEにはNode.jsでの起動方法とDockerでの起動方法が記載されています。

## 目的・背景

- AIエージェントを視覚的に構築するためのツールとして紹介されています。

## 依存関係

- クイックスタートではNode.js 20.0.0以上が必要です。開発者向けセットアップではPNPMを使い、依存関係のインストールにpnpm install、ビルドにpnpm buildを実行します。

## 実行条件

- クイックスタートではFlowiseをインストール後、npx flowise startで起動します。Dockerの手順ではDocker ComposeまたはDockerイメージを利用します。

## 最短手順

- Node.js 20.0.0以上を用意し、npm install -g flowiseを実行してからnpx flowise startで起動します。
