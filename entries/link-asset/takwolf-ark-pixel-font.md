# 方舟像素字体 / Ark Pixel Font

## 出来ること

- 泛拉丁文字と泛中日韩文字に対応する、黑体風のピクセルフォントです。10px・12pxの等幅／比例モードがあり、言語別字形としてlatin、zh-Hans、zh-Hant、zh-HK、zh-TW、ja、koを用意しています。READMEは比例モードについて、字形に応じた文字幅、より自然な字間と行高、字偶距調整に対応すると説明しています。対象文字には不足があります。

## 目的・背景

- 限られたピクセルサイズで文字を表示するためのフォントです。等幅モードは文字を厳密に揃えられる一方、字形の設計空間と対応文字数に制約があるとREADMEに記載されています。READMEは特別な要件がなければ比例モードを推奨しています。

## 依存関係

- フォント構築プログラムの依存先として、Pixel Font Builder、Pixel Font Knife、unicodedata2、Unidata Blocks、Unicode Block Translations、Character Encoding Utils、PyYAML、Pillow、Beautiful Soup、Jinja、Loguru、Cyclopts、pytestがREADMEに列挙されています。

## 実行条件

- フォントの利用条件は、フォントがSIL Open Font License 1.1、構築プログラムがMIT Licenseです。READMEには構築プログラムの具体的な実行環境やバージョン条件の記載はありません。

## 最短手順

- README記載の公式Releasesページからフォントを入手してください。対応文字やサイズはREADMEの文字統計表で確認でき、READMEのPlaygroundリンクで表示をプレビューできます。
